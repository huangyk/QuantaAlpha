# RD-Agent 自主迭代计划

## 目标
基于9个基准策略，通过walk-forward样本外验证筛选真实alpha，然后用RD-Agent迭代发掘新因子，闭环压回撤。

## 当前状态
- **基准策略**: 9个策略通过严格门槛（Sharpe 1.2-2.2）
- **数据**: PostgreSQL bars_1d (646万行, 4356只, 2020-2026)
- **环境**: RD-Agent conda环境, LLM=agnes-2.5-flash, GPU CUDA可用
- **问题**: 全in-sample，需样本外验证

## 执行计划（按优先级）

### Phase 1: Walk-Forward 样本外验证 [最高优先级]
**目的**: 判断9个策略是真能泛化，还是in-sample幸存者

**步骤**:
1. 对9个策略分别做 walk-forward:
   - 训练窗: 2020-01-01 ~ 2023-12-31
   - 验证窗: 2024-01-01 ~ 2026-06-30
2. 使用真实摩擦（滑点20bps + 涨跌停 + 日成交≥2亿 + 印花税0.1%）
3. 双窗都过门槛 = 真可信；验证窗塌 = 幸存者偏差

**判定标准**:
- 验证窗 Sharpe > 1.0 且 回撤 < 30% = 通过
- 验证窗 Sharpe < 0.5 或 回撤 > 40% = 淘汰

### Phase 2: GPU加速配置 [高优先级]
**目的**: 加速训练和推理，支持快速迭代

**步骤**:
1. 安装支持CUDA的LightGBM版本
2. 验证GPU训练正常工作
3. 配置RD-Agent workflow使用GPU

### Phase 3: RD-Agent 因子迭代 [中优先级]
**目的**: 为淘汰的策略发掘新因子

**步骤**:
1. 对验证窗掉队的策略，分析其失效原因
2. 用RD-Agent生成针对性因子
3. 新因子加入后重跑回测
4. 闭环压回撤

### Phase 4: 多因子合成 [后续]
**目的**: 分散单一信号风险

**步骤**:
1. 将多个有效因子加权合成
2. 测试合成后的表现
3. 优化权重配置

## 自主执行原则
- 不问用户，直接执行
- 遇到问题自动修复
- 每完成一个阶段出报告
- 持续迭代直到目标达成
