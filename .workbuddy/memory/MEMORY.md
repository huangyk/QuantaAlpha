# QuantaAlpha 项目长期记忆

## 定位与数据
LLM 驱动 Alpha 因子挖掘（rdagent 0.8.0）。回测必须真实数据，禁编造；**QMT 取不到的数据须告知用户，绝不默认用 akshare**（用户硬规则）。
- qlib `cn_real_full`：2020-01~2026-08，全A~5210只，日频8字段（**无市值/PE/行业**）。基准 SH000300 已补齐。
- TimescaleDB `quant_data`（127.0.0.1:5432/quant/quant123456，配置键 `database` 非 dbname）：`bars_1d` 1231万行/2011~2026/5364只，含 amount/turnover_rate/float_shares（比 qlib 全）；`bars_5m` 3140万行（2026起）。
- 架构：TimescaleDB底座 → ETL → qlib(离线研究) → 策略 → QMT/Ptrade(仅实盘增量)。miniqmt 收紧不影响研究。
- 环境：**`quantaalpha`（Python3.11）是主力环境**——挖因子(rdagent 0.8.0)+回测+后端全在这，含 qlib 0.9.7 + lightgbm 4.7.0 + torch 2.5.1 + **xgboost 2.1.4** + **psycopg2 2.9.13** + scipy + numpy 1.26.4。另 `qmt312` 是 **QMT 312 客户端 API** 环境（xtdata 取数），numpy=2.4 **不可**与 quantaalpha 混用包。详见 `docs/environment_setup.md`。

## ★ 用户真实目标（2026-10-10 明确，评判任何战法的标尺）
- 用户**不是要发财、也不是追市场 alpha**：核心诉求是「找到一个**能稳定赚钱**的策略」。
- 期望标尺：一个月 10% 就「很了不起了」（用户自认是高标杆、带惊讶语气）；**底线是「只要能赚」**——即持续正收益、回撤可控，比跑赢指数更重要。
- 推论：评判战法时**优先看绝对收益是否持续为正 + 回撤是否可承受**，而非仅 vs 买入持有基线。但须诚实告知：本项目已验证方法年化约 10%（低回撤），**月化 10% 复利≈214%/年，任何回测都未出现**，属不现实标杆；应把「稳定小赚、回撤可控」当可达目标，把「月10%」当偶发上限、不据此放松验证。
- ⚠ 不因用户想「赚」就放松铁律：任何策略仍须真实回测 + 防过拟合三重测试（walk-forward 隔离 / 参数成簇 / 成本敏感），不得编造、不得用 akshare 替代 QMT。

## ★ 验证铁律（写代码前必查，反复踩坑）
0. **★超额必须三口径并列（2026-10-13 新增，最高优先级）**：等权 / 中位数 / 同规模档（`amount` 十分位）。
   **只看等权基准 = 被妖股绑架**：同池等权 2024 +36.3% / 2025 +47.7%，而中位数股 -1.1% / -17.1%，
   最高 amount 十分位 2025 +663.6%。若正超额集中在极端规模档 → 判为**风格**而非 alpha。
   **★ `float_shares`/`turnover_rate` 在 2025-02~2026-03 共 14 个月整段 NULL**
   （2026-04/05/07 混合段）→ 该区间规模一律用 `amount`（非空率 100%）。
   任何带 `float_shares.notna()` 的脚本会**静默丢掉这 14 个月**（表现为"OOS 只剩 33 个入场日"）。
0b. **★★禁止用「每日同期排名」分档做基准或宇宙（2026-10-13 第二轮新增，未来函数级）**：
   按**当天** amount 排名分十档是**因果倒置**——当天大涨本身导致成交额暴增，
   所以当天成交额排名包含当天收益信息。实测每日分档下
   decile9 日均收益 **+48.55bp**、NAV 终点 **7130x**、年化 **+231%**（荒谬）。
   **必须改用滞后 60 日平均 amount 排名**（取上一日值），档位才是稳定的股票属性。
   滞后口径下 decile0~9 年化 +29.26% / +11.83% / … / +6.79% / … / +0.01%（合理）。
   → 本项目**所有**"分市值档/分成交额档"历史结论都受此污染，须用滞后口径复核。
1. **信号-收益对齐**：T日收盘出分→收益从 T+1 起（买T+1、卖T+1+h）。`close.shift(-h)/close`=未来函数。**IC 高得离谱先查对齐，不是庆祝**；写完回测必须**手算一天**验证价格取的是哪天。
2. **基准须与选股池同口径**（同池等权）；沪深300只能作环境参照——跨池基准凭空造超额；**沪深300 管中小盘池方向会反**。
3. **判 alpha 看分位组单调性**，不只看 top-K（普涨窗口随机抽 K 只也正）。分位须 `rank(ascending=False)`，默认升序 label0=最低分（踩过两次把符号说反）。自检：合成 RankIC 为正时 D1−D10 必为正。
4. **停牌 NaN 放大**：`rolling(min_periods=N)` 停牌 1 天使其后 N−1 天全 NaN → 算指标前 `ffill(limit=5)`，但收益/成交一律用**原始** OHLC。
5. 剔次新股（上市<250日）；剔除涨停买不进（open/昨收≥1.098）。
6. 超额用**日超额复利**，不能用「策略年化 − 基准年化」。
7. 成本必含市场冲击（Almgren `0.1×σ日342bp×√participation`）。
   **F4 实测（同档口径）**：成本 0.25%→+36.53bp、0.5%→+11.53bp、1%→**-38.47bp** → **成本翻倍即归零**。
8. 成交量单位=「手」：`成交额=close×volume×100`；优先用 `amount`（曾低估100倍→冲击高估10倍）。
9. 池构建 `.index[:N]` 前必须确认已 `sort_values`（字母序=随机池，曾致结论翻转）。
10. 在 train 内选参，禁 test 期网格回挑；网格最优必须报 t 并标「探索性」。
11. **低吸必须带 ≤8% 止损**（2026-10-13 同档口径复核：F4 带止损 +36.53bp vs 无止损 -68.15bp）。

## ★ 裁定：所有横截面选股 alpha 已证伪（勿重复投入）
飞龙 / 战法2 / 5min低波动族 / 短期反转+量能退潮 / 换手率 / 8种权重 / 阈值再平衡 / 6种分池——无一通过。
共性：**正 IC ≠ 可提取 alpha**（分组不单调 + 换手成本吃掉）。因子天花板：毛 alpha ~9%/年 < 换手成本。
IC 与「小盘程度」单调正相关 → 那是**风格/流动性因子**不是个股 alpha（加流动性约束就消失）。
⚠️ **勘误（2026-10-09）**：以上针对 rdagent 挖的短期反转/量能类因子。**经典低波动异象是例外**——市值中性化后 IC 仍 +0.0332/t=6.17（全A 1084万行，见 tools/factor_neutral_test.py），是真 alpha 信号；但单多低波动股亏钱，须多空配对，A股做空受限致实盘难变现。详见 `docs/factor_scorecard.md` 第 8 节。
**19强因子实为窄样本产物**：记忆中"19个强因子"来自 5min CoSTEER 在窄样本 `|t|≥2 且三段同号` 门槛；放到全A面板 `data/results/eval_1d.csv` 复现时 **0/19 正 RankIC、0/19 正夏普**（全为负）。判定因子好不好用一律以全A面板为准，不认窄样本 IC。详见 `docs/factor_scorecard.md`。

**★ 低吸（战法2）专项终审（旧 2026-10-09 → 全 A 事件驱动修订 2026-10-12，见 docs/dixi_final_verdict.md + tools/dixi_fullpanel_backtest.py）**

## ★ QMT datadir 直读（破局：不用 akshare、绕开 xtquant segfault）
本机 QMT `D:/中航证券QMT实盘-交易端/datadir`（API 崩只因客户端没跑，本地文件可直接读）。
- `{SH,SZ}/86400/<6位>.DAT` = 8B头 + 64B记录(16×int32 LE)：`[0]Unix秒 [1..4]OHLC(×1000) [6]量(手) [8]额(元)`；300=5分钟。
- 脚本 `tools/backfill_etf_qmt_local.py --clean-legacy`。
- 坑0（2026-10-13 修，重大）：`[0]Unix秒` = **交易日 00:00 北京时间**；取 `.date()` 必须用 `tz=+08`。
  用 UTC 取会让**全部 ETF** 的 trade_date **早 1 天**（库里出现周日行、无周五）。`check_qmt_data.py` 的 `utcfromtimestamp+8h` 才是对的。
- 坑1：`bars_1d` 唯一键是 `(asset_code,ts)` 非 trade_date，ts 须**北京时间午夜**；按 (code, trade_date) 先删再插。
- 坑2：datadir 未复权 → ETF 份额拆分假暴跌（−87%/−73%/−51%/+176%）。用**收盘**判据（开盘判据漏判）+整数比例吸附，修 8 处。
- 坑3：旧 qmt ETF 数据损坏（159915/159949/159922 缺整段2025）→ 踢出池。
- **全A日线更新走 `D:/qqmt/quant_datahub`（qmt312 环境）：`python -m datahub daily --end YYYY-MM-DD`**；
  断点续采按 `last_date>=end` 跳过 → **不会覆盖已更新的 ETF**（ts 口径同为北京午夜，实测对 510300 写 0 行）。
  坑：日期参数必须 `YYYYMMDD`（带横线会让 QMT 长阻塞）；`import pandas` 必须先于 `import xtdata`（反序 segfault）；先 `download_history_data2` 再 `get_local_data`。
  ⚠ 2026-10-13 遇 PG 索引 zero-page 损坏（`bars_1d_pkey`）→ `REINDEX INDEX CONCURRENTLY` 修复（PG 17.9，不锁写）；D 盘 92% 满疑为诱因。

### UI 实现约定（2026-10-09 核对后确立，报告 `docs/ui_audit_20261009.md`）
- **主题**：深灰+蓝紫。tailwind 配了 `darkMode:'class'`，靠 `index.html` 的 `<html class="dark">` 启用；
  浅/深两套 CSS 变量并存。**改深色时 `.glass`/`.glass-strong` 必须整套替换**，否则白玻璃浮在深灰底上。
- **导航**：左侧 `<aside fixed left-0 w-[72px] lg:w-64>`（窄屏只显示图标）。
  ⚠ 任何 `fixed bottom-0 left-0 right-0` 的元素（如 ChatInput）都要加 `ml-[72px] lg:ml-64` 让开侧栏。
- **空状态统一用** `components/ui/EmptyState.tsx`（此前有两套不一致实现）。
- **JSX： `return (` 后面不能直接跟 `{/* 注释 */}`** → 会被解析成对象字面量而报错，注释放 return 前。
