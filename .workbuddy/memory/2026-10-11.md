## 混合比例前沿（用户"可以啊"批准跑底盘↔H1 五档）
- 新增 `blend_absmomentum` / `run_blend_frontier` / `walk_forward_blend` + CLI `cmd_blend`（写 `docs/blend_frontier.html` 内联SVG散点 + `data/results/blend_frontier.csv`）。
- 模型=核心-卫星：投资者把 (1-blend) 配底盘 sleeve、blend 配 H1 sleeve，各 sleeve 月频调仓、内部可转现金；组合日收益按 blend 加权。blend=0 纯底盘、blend=1 纯 H1。
- **真实结果（全周期 2019-2026，38只ETF）**：
  - H1 100%：年化12.0% / Sharpe0.81 / 回撤−19.2% / 波动14.8%
  - 75%：11.5% / 0.86 / −16.8%
  - 50%：11.0% / 0.91 / −14.4%
  - 25%：10.5% / 0.97 / −11.9%
  - 0%（纯底盘）：10.0% / 1.03 / −9.4%
  - 两端等权基线：全池等权 Sharpe0.71/年化10.9%/回撤−23.0%；高beta等权 0.69/12.0%/−25.7%。**所有混合点的 Sharpe 都跑赢两端等权基线**。
- **walk-forward OOS（隔离测试窗 2023-2026）**：5 档测试窗 Sharpe 全>0（1.04~1.11），混合增强在样本外仍稳定赚钱、非过拟合。blend 是用户风险偏好(非挖掘参数)，测试窗沿用同比例不重选参（无过拟合）。
- **解读**：前沿单调——加 H1 权重=多收益也多回撤、降 Sharpe。8万本金最坏浮亏：纯底盘~7.5k、25%H1~9.5k、50%~11.5k、100%H1~15.4k。均非月10%。让用户挑"回撤能睡着"的点。
- **下一步待用户选点**：选定 blend 后更新战法文档 + `make_order_list.py` 支持混合配置（或新增 blend 版下单生成器）。
