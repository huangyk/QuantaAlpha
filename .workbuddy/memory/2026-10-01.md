  `CODEBUDDY_SAFE_DELETE_SANDBOX=0`、`CODEBUDDY_SAFE_DELETE_BULK_GUARD=""`、`CODEBUDDY_SAFE_DELETE_BULK_STATE_DIR=""`，
  只作用于子进程、不动宿主。已重启后端（新 PID 4776）生效。
- 教训：本环境跑"会批量删自己临时文件"的长驻子进程，必须在启动 env 里显式关掉 WorkBuddy 的 safe-delete 守卫，
  否则会卡死且无报错（只能靠"内存恒定+日志停更+SAFE_DELETE 标记"三特征识别）。

## mining 回测 FAILED 的最终根因（PATH 重写污染 MKL → exit 120）
- 现象（修复前，commit f575f31 已把 qrun 翻译到 `python -m qlib.cli.run`，但仍 FAILED）：
  qrun 正常跑完 LightGBM 训练（l2.train/l2.valid 已写入 mlflow），但在 SigAnaRecord 计算 IC 那一步
  硬崩溃，`mlflow_recorder status=4 FAILED`，artifacts 里只有 pred.pkl/label.pkl、无 sig_analysis/ic.pkl，
  无任何 traceback，进程退出码 120。
- 真正根因：`rdagent_windows_localenv.py` 的 `_windows_localenv_run` 会按 `conf.conda_env_name` 重写 PATH。
  rdagent 的 `QlibCondaConf` 硬编码 `conda_env_name="rdagent4qlib"`（一个独立的 Python 3.10 环境），
  patch 把 `<rdagent4qlib>\Library\bin` 前置到 PATH——里面带了一整套 MKL 运行时 DLL（mkl_*.dll、
  libiomp5md.dll 等），与 quantaalpha 的 Python 3.11 扩展不匹配，导致 numpy/pandas 在 IC 计算时加载到
  版本冲突的原生库而崩溃。
- 关键实验（同一 workspace、同一 conf_combined_factors.yaml）：
  - patched LocalEnv 跑 qrun（前置 rdagent4qlib 或 quantaalpha 自己的 Library/bin）→ exit 120 崩溃。
  - shell=True+PIPE 但不重写 PATH → exit 0；手动 `python -m qlib.cli.run` → exit 0、RankIC=0.056。
  → 结论：**PATH 重写本身就是有害的，不是"换对目录"能解决**。
- 修复（commit ba8b5cc，仅 commit 未 push）：
  - Windows 下完全不重写 PATH（Unix 保持原版逻辑）。
  - entry 统一翻译成用 sys.executable 显式执行：`qrun X`→`"<python>" -m qlib.cli.run X`、
    `python X`→`"<python>" X`（覆盖 qrun / python generate.py / python read_exp_res.py 三条路径）。
  - 删掉失效的 _win_conda_env_paths 死代码 + re/json/time 未用导入。
  - localenv_debug.log 改为仅失败时落盘（runner 只截断打印前 500 字会掩盖真实 traceback）。
- 验证：patched LocalEnv 跑 qrun → exit 0，IC=0.026/ICIR=0.22/RankIC=0.056/RankICIR=0.375。
  端到端重跑 mining（任务 9f91b11f，方向"均线回踩低吸"，suffix exp_lowbuy_v2）→ 因子库
  `all_factors_library_exp_lowbuy_v2.json` 已落真实指标（VolFiltered_MeanReversion_VWAP_Factor 等：
  IC=0.0297 / ICIR=0.270 / RankIC=0.0585 / RankICIR=0.438）。
- 教训：Windows 下跑 qlib，**千万别往 PATH 里前置 conda 环境的 Library/bin**（MKL/OpenMP 运行时 DLL
  版本冲突会以 exit 120 无 traceback 崩溃，极难定位）；需要什么命令就显式用 sys.executable 翻译。
