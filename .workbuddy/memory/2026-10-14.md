### 12. 迁移第 2 步：表达式引擎验证（`tools/qlib_f4_pilot.py`，已完成）
F4 用**一行表达式**实现（不手写 rolling）：
```
|$close - Mean($close,20)| / Mean($close,20) < 0.03  AND  $close > Mean($close,20)
AND Ref($close,1) <= Ref(Mean($close,20),1)
```
**对齐结果（2026-01-05~10-13）**：
| | 信号数 |
|---|---:|
| Qlib 表达式版（加上市≥250日过滤） | **36,050** |
| 手写版（bars_1d 清洗后标尺） | **35,762** |
| 差异 | **288 笔 = 0.8%**（手写版另剔了 ST / 涨停买不进） |
→ **迁移路径验证通过**；且 Qlib 侧 `MultiIndex 重复数 = 0`（框架层天然挡重复行）。

### 13. 踩坑：Windows + Qlib 多进程
- Qlib 的 `D.features` 默认走多进程；**脚本若没有 `__main__` 保护，子进程会重复导入顶层代码
  → 无限递归卡死**（首版卡了 10 分钟无输出）。
- 修复：① 全部代码放进 `main()` + `if __name__ == "__main__":` 保护；
  ② `os.environ["QLIB_KERNELS"]="1"` 禁多进程；③ `multiprocessing.freeze_support()`。
- 修复后耗时 **1m14s**（手写版约 2min）。
