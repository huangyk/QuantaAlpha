## 【结案】平台 RankIC 0.0637 复现不出来 —— 不是 bug，是比错了对象

新增 `tools/diag_rankic_align.py`，一次跑完「定位 run → 读 pred.pkl → 重算 label → 逐日对照」。
**结论：我的 RankIC 算法完全正确（跟 qlib SigAnaRecord 逐日相关系数 1.0000），之前比对不了是因为量纲不同。**

- 平台 RankIC 的定义（`quantaalpha/backtest/runner.py:554-576`）：
  `pred = model.predict(dataset)` → `SignalRecord` 存 pred → `SigAnaRecord` 算
  → 存 `sig_analysis/ric.pkl` → `metrics['Rank IC'] = ric.mean()`。
  **pred 是 LightGBM 对 N 个因子训练出来的「合成分」，不是单因子值。**
- 实测（`workspace_exp_20261001_193237/.../artifacts/pred.pkl`）：
  index 层序 `['datetime','instrument']`，2,069,937 行 × 1 列 `score`，
  unstack 成 **485 天 × 4336 只**（2024-01-02~2025-12-31）。
  用它重算日 spearman：mean=**0.062487**，n_days=482；平台 ric.pkl mean=**0.062487**，
  逐日相关系数 **1.0000**，差值 0.000000 → **复现成功**。
- 所以：单因子 0.017~0.028 → LGB 合成后 0.0626（**≈3 倍增益**）是正常的模型效果。
  我拿「单因子 RankIC」去比「多因子模型 RankIC」当然对不上。悬案关闭。
- **注意数字更正**：`data/results/*/batch_summary.json` 里最高是 **0.0738**（warfare2）/ **0.0689**（bench_csi300，
  但那次是 09-30 14:09 的 run，其 ric.pkl **已不在 data/results 下**，扫描 top15 最高只有 0.0626）。
  记忆里此前记的「平台 0.0637」是近似值，实际可复现的是 0.0626。
- **顺带挖出真 bug**：`configs/backtest.yaml:46 market: "csi300"`，但 qlib 实际
  `D.instruments('csi300')` 只返回 **1 只（SH000300）**（`instruments/csi300.txt` 就一行）。
  而实际跑出来的 pred 覆盖 4336 只全市场 → **runner 实际没走 config 的 market**。
  若在 config 口径下跑，RankIC 每天只有 1 个样本，spearman 无意义。需确认 runner 是否覆盖 market。

### pandas 坑（本脚本踩了 5 个，写同类代码务必避开）
1. `D.features` 与 `SignalRecord` 存的 pred **层序相反**：前者 `['instrument','datetime']`，
   后者 `['datetime','instrument']` → 只能写「保证 datetime 在 level 0」的通用逻辑，别写死 swap。
2. 多层 index 不能只 `droplevel('instrument')` —— 会把标的层整个扔掉，
   面板塌成 206 万行×1 列（首末日期看着正常，其实是假的）。**必须 `unstack('instrument')`**。
3. 对 MultiIndex 表做 `.T` 会把列标签顶成 index 层（index 里冒出 `LABEL0`）。
4. `D.features` 对单表达式可能返回 **Series**，直接 `.columns = [...]` 会炸，要先 `to_frame`。
5. **最隐蔽**：pred/label 两个面板列名都是 instrument 代码（几乎全同），
   直接 `concat(axis=1)` 会产生 8666 个重复列名；就算躲开，取 `.iloc[:,0]` 得到的是
   **某一只票的时间序列**，再 `groupby(date)` 每天只剩 1 行 → 日 rank IC 全 nan
   （实测 inner 后 482 行、n_days=0）。**必须整张面板 `stack()`** 才是日截面。
