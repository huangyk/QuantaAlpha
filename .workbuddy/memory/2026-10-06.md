### 根因（eva_utils.py 真 bug）
`quantaalpha/factors/coder/eva_utils.py:576`：
```python
except json.JSONDecodeError as e:
    raise ValueError("Failed to decode JSON response from API.") from e
```
LLM 偶发返回空串/非 JSON 时**直接 raise，没有重试**，异常冒泡到
`run_evolution_loop` 致整个 `mine` 进程退出。而同级的 `KeyError` 分支有
`attempts += 1` 重试逻辑——JSON 分支漏了。

### 修复（commit 待提交）

重试（关缓存换种子）最多 3 次，仍失败才如实抛出。编译通过。
