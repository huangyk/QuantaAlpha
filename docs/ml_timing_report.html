四、裁定

最优 ML/DL(软加权, v1) = PyTorch MLP(DL) (Sharpe 0.99) 未跑赢始终持有基准

软加权最小回撤来自 PyTorch MLP(DL)：-4.9%(基准 -8.0%) —— 类'降杠杆'效果，回撤减半，对'回撤可控/能睡着'诉求直接有用；但 Sharpe 未超过'恒定比例持有'，说明模型概率没能在下跌前自动变低，即没有真正的择时 alpha，只是把平均暴露降到~60%。

空基准证伪：恒定 60% 持有 = 5.4% / Sharpe 1.03 / -4.8%，而最优软加权(MLP, 平均暴露58%) = 5.1% / Sharpe 0.99 / -4.9%——两者几乎重合，且 ML 的 Sharpe 反而略低于恒定比例持有，即 ML 软加权被朴素'永远持60%'严格 dominate。增强特征(v2)也未改变结论。逐年 OOS 中恒定60%在多数年份 Sharpe ≥ 最优软加权，进一步坐实：本样本下 ML/DL 择时层不创造 alpha。

说明：本环境 sklearn.LogisticRegression.fit() 静默 segfault(二进制兼容bug)，故 ML 用 LightGBM/XGBoost、DL 用 PyTorch MLP；三模型均按 expanding-window walk-forward 训练，预测月用此前全部历史、收益在预测后才'实现'，严格无前视。样本仅~90个月度点(44测试月)，ML/DL 择时(硬/软)均未能稳定击败朴素持有——与项目既有'ML因子证伪'结论一致：叠加层要产生价值，需更大样本或更具预测力的特征，而非单纯堆模型复杂度。已验证的古典趋势跟随(SMA200+逆波动)仍是本池最稳的'能睡着'策略。
