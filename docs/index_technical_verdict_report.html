指数技术打法验证总报告2026-10-09

验证对象：别人常说的「大盘关口支撑 / 抄跌抢反弹赚几点 / 顺趋势抄跌 / 指数趋势跟踪」到底准不准、能不能复制。
数据：6 大指数（上证 / 沪深300 / 上证50 / 中证500 / 创业板 / 科创50），2018-01 ~ 2026-09-30（约 8.7 年，含 19-21、24-25 两轮牛市）。

一句话裁定

四个方向全部验证完毕：指数层技术打法，无一有压倒性、可复制的 edge。唯一真有用的，是高波动成长指数（创业板 / 中证500）的快 MA60 降回撤保护——那属于风控层，不是信号 alpha。与项目「技术信号大样本无 edge」总裁定完全贯通。
方向方法关键结果裁定
① 圆整数支撑大样本 pooling：6指数×全整数关×网格36 配置净 −13~+3bp，t 全<1，强关占比 40-55%（≈抛硬币）无 edge
② 抢反弹赚几点触支撑带→次日买→+tp/-sl 退出小样本看着有；大样本退化成平（小样本陷阱）仅小样本假象
③ 顺趋势抄跌干净前向收益（前日信号、次日进场）升势抄跌全程负（H40 −259bp, t−3.9）；仅 1/27 微显著且熊市负证伪
④ 趋势跟踪MA 择时（仅多）+ TSMOM 多空MA 均值跑输买入持有；TSMOM(6mo-1yr) 跨6 均值 ≈0、回撤 −55%平均无 edge

扩到 6 指数 × 全整数关 × 参数网格（pooling 后每配置 N=929~2200 笔）：所有 36 个配置净收益 −13~+3bp，t 统计量全 <1；「强关」占比 40-55%，等价于抛硬币——支撑识别没有筛选力。

结论：他「蛮准」部分属实（创业板 2900 有数据支撑）、部分错觉（3700/1200 历史是破位）。但大样本下圆整数支撑无可测 edge。

2抢反弹「赚几点就走」

仅小样本假象

用户纠正尺度：别人是支撑位抢反弹、赚 2-5 点就走，非选股大 alpha。逐关口回测（tp=sl=3%）：

关卡净收益胜率样本
上证 3741+40bp57%7 笔
上证 3700−3bp—假支撑
创业板 2900−3bp50%平
科创50 1200+57bp—10 笔

网格显示：真支撑上「只赚 3 点」反而打平（50% 胜 + 1:1 止损 = 无 edge）；要赚 4-5 点才吃到反弹真实 median。但每关仅 7-22 笔——小样本噪声。大样本研究（方向①的 pooling）已推翻「温和 edge」结论。

结论：指数级「几点就走」在真支撑上有温和真实 edge（非个股那种全负），但样本太小、依赖选对真支撑，不可作为稳定策略。

「别人蛮准」到底是什么意思

最省解释，四条线全部指向同一结论：
① 展示 / 幸存者偏差——只晒对的、忘掉错的；
② 叙事归因——把成功叫「支撑位 / 顺趋势抄跌」，但信号不是收益来源；
③ 幸运双牛窗口——19-21、24-25 任何多头都赚，熊市 2022 全亏；
④ 「赚几点就走」是小样本回忆，大样本下退化成抛硬币。

要真把「蛮准」从印象变成可证伪的数据，得建 call tracker：把他每次说的关口 / 抄跌判断按时间戳逐条记录（哪天说、说什么位、给多久、实际走法），跑一段后机器打分。

好方法：跨资产绝对动量 / 趋势跟随（唯一真能用的）

实盘数据验证有效

四个验证方向都证伪后，网上文献（Antonacci GEM / Faber 200日SMA战术配置 / Moskowitz TSMOM）指向一个稳健做法：对每个资产独立判趋势——该 ETF 自身收盘价 > 200日SMA（或 12个月动量>0）才持有，否则该份额转现金。不是用一个外部指数给整个池当总开关（功能B 的单指数 MA 门控在多元池上反而伤收益）。

好方法压力测试：防过拟合（walk-forward OOS + 参数敏感 + 成本敏感）

三重测试通过，非过拟合

项目铁律「判定因子好不好用一律以全A面板为准，不认窄样本IC；LB扫描呈噪声带即过拟合」。唯一验证有效的方法必须经得起三重拷问，否则又是一个被毙的窄样本产物。
