## 0. 一句话结论

**风险构建（ERC / 逆波动）在 A 股大市值池上稳健优于等权，也稳健优于沪深300——
但它是「减伤 + 相对跑赢」工具，不是「造收益」工具：绝对收益仍为负，因为 2021-2024
A 股大市值本身就是亏钱 regime。**

这是本项目第一个在「纯股票、只做多、含成本、同宇宙同再平衡」口径下
**逐年跑赢沪深300** 的东西。但它没有、也不能把亏钱的市场变成赚钱的市场。

## 1. 为什么测这条（没试过的那条路）

低波动异象因子是**真的**：市值中性化后 RankIC = +0.0332，t = 6.17（全 A 1084 万行）。
但两种变现方式都已在本项目证伪：

| 变现方式 | 结果 | 证伪原因 |
|---|---|---|
| 笨选低波个股纯多 | 年化 **−34.0%** | 低波名单是事后静态的，regime 一变就失效 |
| 多空配对 | 日频 **−29.7%** / 月频 −0.69% | 成本 + A 股做空受限 |

**没试过的是组合构建路线**：最小方差 / 逆波动 / 风险平价（ERC）。
它们不「挑低波的名」，而是用**协方差结构**把权重压向低波、低相关资产 → 天然只做多、
天然分散、无需做空。这正是本项目此前没覆盖的层面（SOP §7 自认的短板）。

## 2. 方法（与 SOP 对齐）

| 项 | 口径 |
|---|---|
| 宇宙 | **总市值 top-N**（= 收盘价 × 总股本），N ∈ {300, 500, 1000}；剔次新（上市<250日）、剔日成交额<1亿、剔涨停开盘 |
| 为什么不用「成交额 top-N」 | 那是**注意力/动量陷阱**（本项目早前实测全期 −88% 回撤），且按当日 amount 排名含当天收益信息 = 未来函数 |
| 再平衡 | 月末收盘定权重（只用截至当日数据）→ **次月首个交易日**起生效（T+1 对齐，无未来函数） |
| 协方差 | 近 120 日日收益，**Ledoit-Wolf 常数相关收缩**（δ=0.30，不用原始样本协方差——500 只时噪声炸） |
| 构建方法 | 等权 EW / 逆波动 InvVol（w∝1/σ）/ ERC（迭代等风险贡献）/ MinVar（长多 QP，0≤w≤cap） |
| 成本 | 佣金 1bp + 印花税 5bp（仅卖，按 0.5 折算）+ Almgren 冲击（0.1×σ342bp×√参与率）；换手按权重 L1 变动计 |
| 复权修正 | 单日 \|收益\|>21% 物理不可能（主板±10%/双创±20%/ST±5%）→ 判为未复权除权跳变，用当日横截面中位数填充（实测剔除 1685 个） |
| 去重 | `(asset_code, trade_date)` 重复行先 `drop_duplicates`（本项目已知数据坑，曾致 730 天显示成 2920 天） |

**环境坑（已记）**：本环境 cvxpy 1.7.5 的 OSQP / SCS / CLARABEL 全部让进程**静默硬崩**
（无 traceback、exit code 0）。MinVar 改用纯 numpy **FISTA + Dykstra 投影**自写 QP，
已对 KKT 一阶条件验证通过（Σw=1 精确到 1e-8、自由变量 (Σw)_i 全等、边界变量符号正确），
0.73 s/次（n=500）。**这是本项目后续要用 QP 时的唯一可靠路径。**
