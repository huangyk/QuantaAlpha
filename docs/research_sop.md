> 用途：本项目**所有**战法 / 因子 / 策略研究的统一流程。任何新信号在"出结论"前必须逐关通过本规范。
> 来源：① 行业公认因子研究链路（生成→清洗→中性化→IC→分层→样本外→参数高原）；② 本项目已验证的 8 条铁律 + 3 个数据坑的硬经验。
> 定位：本规范是**底线**（对标"机构 3~4 年研究员"水平）。明确不覆盖组合构建 / 风险模型 / 现代深度学习 / 期权高频（见 §7）。

## §1 研究流水线（强制顺序）

任一信号（战法 F1–F10 / 原子因子 / 组合策略）按以下 10 步走，**前一步不过不做下一步**：

1. **信号定义（精确化）**
   - 写成可计算表达式，明确：触发日（T 日收盘）、买点（**T+1 开盘**，A 股 T+1）、最早卖点（**T+2 收盘起**）、止损/止盈、最大持有期。
   - 禁止"盘中出现""盘中涨停"等无法用日线收盘复现的模糊描述。

2. **数据接入（真实源，禁编造）**
   - 权威源 = TimescaleDB `bars_1d` / `bars_5m`（127.0.0.1:5432/quant）；QMT 直读 `D:/中航证券QMT实盘-交易端/datadir` 兜底。
   - **铁律：QMT 取不到的数据须告知用户，绝不默认用 akshare 替代。**
   - 有效可交易历史 = **2020–2026**（2011–2019 过稀、2025–2026 未全回填 → "16 年"结论无效）。

3. **数据清洗**
   - 停牌 NaN：`ffill(limit=5)` 后再算指标；**收益/成交一律用原始 OHLC**（禁对价格 ffill）。
   - 次新股：上市 <250 日剔除。
   - 涨停买不进：open/昨收 ≥ 1.098 剔除（无法成交）。
   - 复权前视：用 `ts` = 北京时间午夜 + `trade_date`；QMT 未复权数据用**收盘**判据 + 整数比例吸附修假暴跌。

4. **异常值 / 缺失 / 分布**
   - 异常值：去极值（winsorize，如 1%/99% 分位截断）——F4 OOS 去极值后 −1.89bp vs 原 −12.23bp，必须报两端。
   - 缺失：上文 `ffill`；不以 `notna()` 默默丢段（见 §6 坑 A）。
   - 分布：IC 用 **RankIC**（对分布稳健）；因子值用 rank 或 zscore 标准化。

5. **中性化（规模控制）**
   - 规模代理 = **滞后 60 日平均 `amount`**（取上一日值）。⚠️ 2025-02~2026-03 `float_shares`/`turnover_rate` 整段 NULL，**这 14 个月规模只能用 `amount`**。
   - 基准须与选股池**同口径**（同池等权）；沪深300 只能作环境参照，管中小盘池方向会反。

6. **前向收益（forward return）对齐**
   - T 日收盘出分 → 收益从 **T+1** 起（买 T+1、卖 T+1+h）。`close.shift(-h)/close` = 未来函数。
   - **IC 高得离谱先查对齐，不是庆祝**；写完回测必须**手算一天**验证价格取的是哪天。

7. **IC 与分层回测**
   - 算 RankIC（全样本 + 分段），报告 t 统计量。
   - **分位组单调性检验**：`rank(ascending=False)`，默认升序 label0=最低分。合成 RankIC 为正时 D1−D10 必为正；**只盯 top-K 不够**（普涨窗口随机抽 K 只也正）。
   - 判 alpha 看**分位单调性**，不只看 top-K。

8. **三口径基准并列（★最高优先级，防妖股绑架）**
   - 必须同时报：**等权 / 中位数 / 同 amount 十分位**。
   - 理由：同池等权 2024 +36.3% / 2025 +47.7%，但中位数股 −1.1% / −17.1% → 等权被少数高成交额妖股驱动。**只看等权 = 被妖股绑架**。
   - 若正超额集中在极端规模档 → 判为**风格**而非 alpha。

9. **样本外 + 成本敏感 + 参数高原**
   - **OOS**：walk-forward 隔离 train/test；train 内选参，禁 test 期网格回挑；网格最优必须报 t 并标"探索性"。
   - **成本**：必含市场冲击（Almgren `0.1×σ日342bp×√participation`）。F4 实测：0.25%→+36.53bp、0.5%→+11.53bp、1%→**−38.47bp** → **成本翻倍即归零**。
   - **参数高原**：扫描参数网格，确认是"高原"（稳健）而非"尖峰"（过拟合）。ETF TSMOM 实测 vt×λ 全网格 Sharpe 仅 0.56~0.64 = 高原无尖峰。

10. **出结论 + 归档**
    - 状态标 ✅证实 / ⚠️待观察 / ❌证伪，写入 `docs/warfares_catalog.md`。
    - 低吸类**必须带 ≤8% 止损**（不带止损的结论无效：F4 带止损 +36.53bp vs 无止损 −68.15bp）。
    - 诚实标注数据边界：2025–2026 OOS 是否验证、有效样本区间。

## §3 基准与规模约定（写死）

- **基准三口径**：等权 NAV + 中位数股 NAV + 同 amount 十分位 NAV（10 档）。
- **分档排名**：`amount.rolling(60).mean().shift(1)` 跨节排序分十档；**禁止用当日排名**。
- **规模代理优先级**：`float_shares`（非 NULL 时）> 滞后 `amount`（2025-02~2026-03 唯一可用）。
- **涨停/停牌日**：不入选股池；收益用原始 OHLC。

---

## §4 成本模型

```
冲击成本 = 0.1 × σ_日(342bp) × √participation
participation = 日均成交额占比
总往返成本档位：0% / 0.25% / 0.5% / 1%（必报四档敏感性）
```
- 任何策略在 1% 往返成本下转负 → 标记"对成本极度敏感，实盘难变现"。

---

## §5 验证关卡（出 ✅ 前必须全过）

1. 信号-收益对齐手算验证（一天）。
2. 三口径基准全列出，正超额不在单一极端档。
3. 分位单调性成立（D1−D10 符号与 RankIC 一致）。
4. OOS（walk-forward）方向不反转；若反转标 ⚠️ 而非 ✅。
5. 成本 0.5% 档仍为正（或明确标注失效阈值）。
6. 参数网格呈高原非尖峰。
7. 低吸类带 ≤8% 止损对照（无止损必须更差）。

## §6 已知数据坑（必读，避免重踩）

- **坑 A（float_shares 空窗）**：2025-02~2026-03 共 14 个月 `float_shares`/`turnover_rate` 整段 NULL。任何 `float_shares.notna()` 过滤会整体丢这 14 个月（表现为"OOS 只剩 33 个入场日"）。规模改用 `amount`。诊断：`tools/_db_float_shares_gap.py`、`tools/_db_missing_months_diag.py`。
- **坑 B（等权被妖股绑架）**：同池等权在 2024-2025 由少数高成交额妖股驱动，不能代表典型股。诊断：`tools/_benchmark_sanity.py`。
- **坑 C（每日分档未来函数）**：见 §2 第 11 条。诊断：`tools/_decile_anomaly_diag.py`、`tools/stable_bucket_rerun.py`。
- **坑 D（nav 键错位）**：`nav_map` 用 `np.datetime64(ts)` 作键 vs `arr_date`(numpy datetime64) 哈希不同 → 100% miss → 0 笔。修复：用 `ts.date()` 字典键。位置：`tools/dixi_fullpanel_backtest.py`。

## §7 本规范刻意不覆盖的部分（诚实边界）

文章自承认其体系只到"机构 3~4 年研究员"，以下内容**不在本研究规范内**，也是本项目当前薄弱项：

- 组合构建（Portfolio Construction，评分 6/10）：目前仅有等权/逆波动/波动率目标等简单权重。
- 风险模型（Risk Model，5/10）：无因子风险分解、无 Barra 式暴露控制。
- 现代深度学习（5/10）：无 Transformer/GNN 等，因子仍以量价/低波为主。
- 期权 / 高频 / 做市：完全未触及（主动选择）。

> 若未来要"超越这套底线"，从上述四项补，而非在横截面选股里继续挖（本项目已证伪：所有横截面选股 alpha 天花板 ~9%/年 < 换手成本）。

## §9 一句话准则

**真实数据 → 信号对齐 → 三口径基准 → 滞后分档防未来函数 → 成本敏感 → 参数高原 → 低吸必止损。**
任何一环跳过的"回测"都不算数。
