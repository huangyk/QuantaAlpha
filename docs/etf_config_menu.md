## 1. 四个可选配置

### 配置 A：收益优先（现役底盘）
**规则**：每月末对每只 ETF 判 `close > SMA200`，通过者按**逆波动率**加权
（σ = 60 日年化波动，下限 0.05），跌穿均线的清为现金。月频调仓。

| 指标 | 数值 |
| :--- | :--- |
| 年化 | **+8.18%** |
| 夏普 | **0.78** |
| 最大回撤 | **−13.9%** |
| 测试期(23-26) | +17.66% / 1.81 / −10.1% |
| 千1 成本 | +7.81% / 0.75（换手仅 28 次/7.7年） |
| walk-forward | 训练 +2.06%/0.24 → 测试 +17.66%/1.81 |

- ✅ **夏普最高、回撤最小之一**，是本项目唯一经 QMT 实盘数据验证的策略
- ✅ 参数成簇：SMA150~250 × vol40~90 九组全部 +6.8%~+9.0%/S0.73~1.01
- ⚠️ **文档数字不可复现（已修文档，见 §6）**：`docs/strategy_absmom.md` 原文写
  +10.0%/1.03/−9.4%，但按代码 `INV_VOL_FLOOR=0.05` 实跑是 **+8.57%/0.86/−11.0%**；
  只有 floor≈0.10~0.15 才能到 +10.0%。**以代码为准：≈ +8.5%/0.86/−11.0%**
  （表中 +8.18% 是 v4 口径——允许标的后期上市，更严也更真实）

### 配置 B：平衡（TSMOM 全池等权）
**规则**：每月末判 12M 动量 > 0，通过者**等权**持有，动量为负的清为现金。月频。

| 指标 | 数值 |
| :--- | :--- |
| 年化 | **+7.63%** |
| 夏普 | 0.58 |
| 最大回撤 | **−16.0%** |
| 测试期(23-26) | +16.43% / 1.17 / −12.1% |
| OOS(25-26) | +38.51% / 2.30 |
| 千1 成本 | 年化几乎不变（换手仅 25 次） |

- ✅ **6 个池变体下全部降低回撤**（−22.2%→−16.0%、−29.4%→−21.0%、
  −36.1%→−26.1%、−26.0%→−17.6%）→ **择时有效性与池选择无关，是真机制**
- ✅ 动量窗口 6/9/12/15/18M 全部有效（+12.78/+11.92/+10.38/+10.27/+9.12%）
- ⚠️ 年化多数略低于等权基准 → **它的价值是降回撤，不是提收益**

### 配置 C：回撤优先（TSMOM + 波动率目标 + 逆波动权重）
**规则**：配置 B 的信号，权重改为 λ=1.0（纯逆波动），
并加**组合级波动率目标 vt=5%**（组合年化波动超 5% 就按比例降暴露）。

| 指标 | 数值 |
| :--- | :--- |
| 年化 | **+4.20%** |
| 夏普 | **0.64** |
| 最大回撤 | **−8.1%** |

- ✅ **回撤只有基准的 1/3**（−8.1% vs −22.2%），夏普仍 0.64
- ✅ vt 与 λ 都是**连续谱参数**（非尖峰）：
  vt 5%→15% 年化 4.20%→6.88% 单调、回撤 −8.1%→−11.7% 单调
- ⚠️ 年化只有 +4.20%，**收益牺牲明显**

### 配置 D：极度怕回撤（TSMOM + weighted 波动率目标）
**规则**：同 B，但波动率目标用**持仓加权波动**（前瞻估计，而非组合已实现波动），vt=6%。

| 指标 | 数值 |
| :--- | :--- |
| 年化 | **+2.86%** |
| 夏普 | **0.72** |
| 最大回撤 | **−4.3%** |

- ✅ **回撤压到 −4.3%**，夏普 0.72（全家族最高）
- ⚠️ 年化仅 +2.86%，接近货币基金水平

## 2. 怎么选

| 你的诉求 | 选 | 预期 |
| :--- | :--- | :--- |
| **能赚就行，想多赚** | A 现役底盘 | ~+8.5%/年，回撤 ~−11~14% |
| **收益和回撤都要** | B TSMOM 等权 | ~+7.6%/年，回撤 ~−16% |
| **回撤别超过 10%** | C TSMOM+vt5%+逆波动 | ~+4.2%/年，回撤 ~−8% |
| **回撤别超过 5%** | D TSMOM+vt6%(weighted) | ~+2.9%/年，回撤 ~−4% |

**关于"月化 10%"**：月化 10% 复利 ≈ **年化 214%**。本项目七轮回测
（含股票侧 F1-F10 + 17 个技术/门控信号 + ETF 时序动量族）
**没有任何策略接近这个数字**。已验证的上限就是年化 8~10%。
把"年化 8~10%、回撤可控"当可达目标，把"月化 10%"当偶发上限。

## 4. 已证伪、不要再用（七轮累计）

**股票侧（正式定案，不再投入）**：
- 通达信 6 战法：战法1/3/4/6 证伪；战法2(F4)、战法5(F7) 由 ✅ 下调
  （同档口径 F4 IS −9.90/OOS −68.91bp；F7 IS −54.88/OOS −62.31bp）
- 10 个横截面技术信号（S2突破/S3缩量回踩/S4 MACD/S5 RSI50/S7量价齐升/S8低波突破等）：
  同档口径 IS 全负或≈0、OOS 全负
- 7 个门控/时序信号（G1 纯门控/G2 个股TSMOM/G3 低波+趋势/G4 均线多头/
  G5 突破+门控/G6 量价齐升+门控/G7 回踩+门控）：同档口径全负
- **根因**：A 股正超额集中在最低成交额档（小盘风格），
  而小盘风格 2025-26 已崩塌；中位数口径的"正超额"是风格效应不是 alpha

**ETF 侧已证伪的层**：
- 朴素 top-K 动量集中（回撤比等权还大）
- 回撤降级 dd_guard（年化掉到 6~7.8%、夏普 0.45~0.57，回撤却没改善）
- 两层风控叠加（vt+guard 互相打架）
- 最小方差 / 风险平价 ERC（年化 +0.06%/+2.04%，远输等权）
- 波动率上限 10%（把暴露砍半，回报同比例腰斩）
