# 日线级别交易计划系统（5分钟选股信号 → 日线确认 → 次日开盘执行）

> 代码：`quantaalpha/strategy/daily_trade_plan.py`　示例输出：`data/results/trade_plan_2026-09-04.json`
> 数据：Qlib `cn_real_full` 日线（真实数据，无模拟/随机成分）。

---

## 一、核心设计：信号与执行的时间差

**5分钟信号只做盘中预警，不成交。** 完整链路：

```
盘中(5min)  →  候选预警（当日可见，不可买入）
T日收盘      →  ★真正的信号确认（日线四条件全中 = A层确认）
T+1开盘      →  按跳空规则决定是否买入（限价委托）
持仓 3~10 交易日 → 分档止盈 / 止损 / 趋势破坏离场
```

- **信号确认条件（T 日收盘，四项须同时成立 → A层）**：
  1. `F3 趋势多头`：`MA20 > MA60`
  2. `F4 回踩金叉`：`close > MA20` 且 `|close−MA20|/MA20 < 3%` 且 `昨收 ≤ 昨MA20`（金叉）
  3. `F2 放量确认`：`volume > 1.5 × MA5(volume)` 且 `volume > 昨量`
  4. `低波动过滤`：当日振幅 `(high−low)/close ≤ 8%`（剔除情绪高潮/异常日）

- **B层观察名单**：满足①且②③④中任意两项，按优先级排序，仅供人工参考，**不自动下单**。

- **次日开盘委托 / 跳空处理**（`build_order_intent`）：以 T 日收盘为参考基准，
  T+1 实际开盘时：
  - 高开 > `3%` → **放弃买入**（不追高）
  - 低开 > `5%` → **放弃买入**（规避接飞刀）
  - 其余 → 以 `开盘价 × 1.002` 挂**限价买入**（留 0.2% 容错保证成交）

## 二、选股逻辑

| 环节 | 规则 |
|---|---|
| 候选池 | `liquid500`（日均成交额筛选后的 500 只） |
| 流动性过滤 | 近 20 日**日均成交额 ≥ 3000 万**（低于剔除） |
| 上市时长 | ≥ 120 个交易日（规避次新暴涨暴跌） |
| 剔除 ST/退 | 名称含 `ST` / `退` 剔除 |
| 剔除停牌 | 近 5 日有缺失收盘价剔除 |
| 剔除一字板 | 当日 `high=low=close` 且涨幅 >9%（买不进）剔除 |
| 量价配合 | 强制要求放量确认（可 `need_vol_confirm=false` 关闭） |
| 优先级排序 | `分 = 2.0(趋势) + 1.5(回踩) + 1.0(放量) + 0.5(平静度) + 0.5(流动性)`，降序 |

## 三、每只标的的交易计划字段（要求2）

| 字段 | 含义 |
|---|---|
| `buy_low/buy_high` | 买入区间（T日收盘 ±0.2%，实际按次日开盘调整） |
| `position_pct` / `shares` | 仓位建议（风险平价，见下） |
| `stop_loss` / `stop_pct` / `stop_basis` | 止损位、止损幅度、依据（ATR×2 与支撑位取近者） |
| `atr` | 真实波幅均值（TR=14日） |
| `tp1/tp2/tp3` | 分档止盈（强制递增） |
| `resistance_note` | 压力位（近 20 日高点） |
| `holding_period` | 持仓周期预期（3~10 交易日波段） |
| `sell_triggers` | 卖出触发条件（见第五节） |

## 四、参数默认值（要求4）

| 参数 | 默认 | 含义 |
|---|---|---|
| `ma_fast/ma_slow` | 20 / 60 | 均线趋势与回踩基准 |
| `pullback_tol` | 3% | 回踩容忍带 |
| `vol_surge_mult` | 1.5 | 放量倍数 |
| `range_max` | 8% | 当日振幅上限（低波动偏好） |
| `atr_period/atr_stop_mult` | 14 / 2.0 | 止损 = 参考价 − 2×ATR |
| `stop_floor_pct / stop_cap_pct` | 4% / 12% | 止损幅度下限/上限 |
| `support_lookback` | 10 | 支撑位取近 10 日最低 |
| `tp1/2/3_atr_mult` | 1.5 / 3.0 / 4.5 | 分档止盈（ATR 倍数） |
| `tp1_pct` | 6% | 第一档止盈下限 |
| `risk_per_trade_pct` | 1% | 单笔风险占总资产 |
| `max_position_pct` | 15% | 单票仓位上限 |
| `max_total_position_pct` | 60% | 总仓位上限 |
| `max_new_positions` | 5 | 单日最多建仓数 |
| `max_gap_pct / max_gap_down_pct` | +3% / −5% | 跳空放弃阈值 |
| `min_amount_cny` | 3000万 | 流动性下限 |

**仓位（风险平价）**：`股数 = min( 单笔风险预算 / (止损幅度×参考价), 单票上限/参考价 )`。
例：止损 4% → 风险预算 1% ÷ 4% = 总仓位 25%，被单票 15% 上限截断。

## 五、卖出触发条件

- **止损**：收盘跌破止损位 → 次日开盘卖出；若次日直接跳空低于止损，开盘市价了结。
- **止盈分档**：T1 减 1/2，T2 再减 1/3，T3 清仓。
- **趋势破坏**：收盘跌破 MA20 → 离场。
- **信号失效**：MA20 下穿 MA60 → 离场。
- **时间止损**：持有 >10 个交易日仍未触及 T1 → 离场。

## 六、适用市场与失效场景（要求4）

**适用**：A 股**趋势性上涨/震荡偏强**的个股，趋势明确（MA20>MA60）+ 短期回踩 MA20 + 缩量回调后放量确认的波段场景。适合流动性充足的中大盘（成交额 ≥3000万）。

**失效场景（务必规避）**：
1. **震荡市/无趋势**：MA20 与 MA60 反复缠绕，信号频繁失效、连续止损。→ 应对：震荡期空仓或降仓。
2. **单边下跌趋势**：趋势过滤（MA20>MA60）会滞后，抄底即被套。→ 应对：需大盘配合。
3. **突发消息/政策/财报**：跳空缺口大，可能直接跳过止损位。→ 应对：持仓期间遇重大公告缩量规避。
4. **一字涨停/跌停**：买不进或卖不出（已在筛选端剔除买入侧一字板，但持仓侧跌停仍无法止损）。
5. **低流动性小盘**：滑点大，止盈难以按预期成交。→ 已用成交额下限过滤。
6. **财报窗口**：业绩暴雷风险，避免在窗口期建仓。
