## ① 深灰背景 —— 原来其实是纯白，不是"主题没生效"那么简单

`tailwind.config` 里配了 `darkMode: 'class'`，**但 `<html>` 上从来没有 `class="dark"`**，所以那套深色变量压根没被创建过。实际生效的是 `:root` 里的浅色值：

```css
--background: 0 0% 100%;      /* 纯白 */
.glass { background: rgba(255,255,255,0.7); }   /* 白玻璃 */
```

**修法（做成可切换，不想用能一键回退）**：保留原浅色变量不动，新增 `.dark` 整套深色变量，并在 `index.html` 挂 `class="dark"`。

- 深灰底 `--background: 222 24% 8%`，主色改蓝紫 `--primary: 250 80% 68%`
- **关键：`.glass` / `.glass-strong` 必须整套替换成深色版**，否则深灰底上会出现一块块白色玻璃板，比全白还难看
- `gradient-mesh` 的光晕透明度 0.15→0.22、色调改偏紫，深色下才看得出来
- **回退方式**：把 `index.html` 里的 `class="dark"` 删掉即可，两套变量互不影响

## ② 左侧导航 —— 原来是顶部 fixed header

原先 `<header className="fixed top-0 left-0 right-0 ...">` 横栏 + 横排按钮，主内容 `pt-24` 全宽。
`ProgressSidebar.tsx` 虽然名字带 Sidebar，但它在 `MiningDashboardPage` 里是放在 `lg:col-span-1` 的**内容区左列**（任务进度面板），不承担导航。

**改法**：
- 新增 `<aside className="fixed left-0 top-0 bottom-0 w-[72px] lg:w-64">`：Logo + 竖排导航
- 响应式：窄屏只显示图标（`w-[72px]`），≥lg 展开成 `w-64` 带文字；标语加 `title` 兜底
- 主内容 `ml-[72px] lg:ml-64 pt-8`
- ⚠️ **连带修复**：`ChatInput` 是 `fixed bottom-0 left-0 right-0`，不加处理会横跨压在侧栏上 → 同步加 `ml-[72px] lg:ml-64`
