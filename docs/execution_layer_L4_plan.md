## 0. 命题与前置假设

**命题**：此前证伪的信号（F4 回踩MA20 等），其失效主因是**换手与冲击成本**而非信号本身；
用 5 分钟数据优化成交方式（降冲击）+ 过滤劣质信号（降换手），可把净超额拉回正。

**前置关 E0 已判定猎物**（2026-01-05 ~ 2026-10-13，唯一有 5m 的窗口）：

| 信号 | 毛超额 | 0.25% | 0.5% | 1% | 判定 |
|---|---:|---:|---:|---:|---|
| **F4 回踩MA20** | **+13.00bp (t=+3.45)** | **−12.00bp** | −37.00 | −87.00 | ★毛边还在，纯被成本吃掉 |
| **S2 突破** | **+13.05bp (t=+2.51)** | **−11.95bp** | −36.95 | −86.95 | ★同上 |
| F6 黄金坑 | +0.87bp (t=+0.15) | −24.13 | −49.13 | −99.13 | 毛边≈0，信号本身弱 |
| F5 首阴 | −3.58bp (t=−0.24) | −28.58 | −53.58 | −103.58 | 信号已死 |

> 规则：**T+1 开盘买、最低价止损 −8% / 最高价止盈 +10% / 最长 20 日**；基准 = 同期全池等权（与策略同口径）。

**量化目标**：F4 需把每笔成本从 25bp 压到 **≤13bp**（降本 ≈48%）才能打平。
固定成本（佣金+印花税）≈ 9~10bp 不可降；冲击剩约 15bp，TWAP 理想砍半 ≈ 7.5bp
→ **单笔降本理想下限 ~17.5bp，仍 > 13bp**，故**必须兼打"降换手"**（过滤劣质信号）。

## 1. 数据口径

| 层 | 表 | 区间 | 说明 |
|---|---|---|---|
| 信号层 IS | `bars_1d` | 2020-01-02 ~ 2024-12-31 | 日线出信号 |
| 信号层 OOS | `bars_1d` | 2025-01-01 ~ 2026-10-13 | 已更新到最新 |
| **执行层实验** | **`bars_5m`** | **2026-01-05 ~ 2026-10-13** | ⚠ 5m 仅此区间，48 根/日、9:35 起 |

`bars_5m` 字段：`ts / trade_date / asset_code / open / high / low / close / volume / amount`
（10-13 已覆盖 5383 只，48 根/只/日）。

### 三条硬约束
1. **信号用 T 日收盘**，成交**只能用 T+1 及以后的 5m** → T 日 5m = 未来数据，禁用。
2. **VWAP 只用同日 5m 聚合**（`Σamount / Σvolume`），不得使用 T 日或跨日数据。
3. **participation 用「该日该股 5m 日内成交额」**（即当日真实可得流动性）。

### 一致性校验（E1 前必做）
抽 20 只标的 × 若干日，核对 `Σ5m.amount == bars_1d.amount`（同源不同粒度，误差应 <0.5%）。

## 2. 成本模型（对齐 SOP §4）

```
固定成本 = 佣金 0.05%(卖) + 佣金 0.05%(买) + 印花税 0.025%(卖) ≈ 9~10bp / 往返
冲击成本 = 0.1 × σ_日(342bp) × √participation
participation = 单笔委托金额 / 当日该股 5m 日内成交额
往返档位（必报四档）：0% / 0.25% / 0.5% / 1%
```

**注意口径差异**：C0 基线用「T+1 开盘价」为成交价，**未含** 5m 内的滑点与冲击；
C1/C2 用 5m VWAP/TWAP，**已内生包含**当日流动性冲击。
→ 各执行组之间的净差额 Δ = 只在成交价不同，**成本模型必须相同**，否则不可比（这是本实验最容易被做错的地方）。

| 层 | IS | OOS | 说明 |

| 信号层 | 2020–2024 | 2025–2026 | walk-forward 隔离，train 内选参 |

- 任何全区间网格最优必须**报 t + bootstrap 97.5% CI** 并标注「探索性」；
- 结论只写"2026 区间内有效"，不外推。

## 4. 实验矩阵

### E1 买入执行（核心；第一步先做）
同一信号、同一区间，**只换成交方式**：

| 组 | 成交方式 | 实现要点 |
|---|---|---|
| `C0` | T+1 开盘价 | 现有基线，无 5m |
| `C1` | T+1 **全天 5m VWAP** | 假设按成交量加权均匀下单 |
| `C2` | 开盘后 **30 / 60 / 120 分钟 TWAP** | 等时间切片，用该窗 5m VWAP |
| `C3` | **缺口过滤** + C1 | T+1 开盘涨幅 > 3% 则放弃该笔（不追高） |
| `C4` | **限价单** = C1 − 20bp | 需判「该根 5m 最高价 ≥ 委托价」才成交，否则收盘价补 |

**成交可行性判据（E1 必须实现）**：
- 限价组要逐根扫描 5m，满足价即视为成交，成交价 = 委托价（保守）；
- 停牌日（该日 5m 根数 < 48 或无首根）剔除；
- T+1 若 open/昨收 ≥ 1.098 剔除（涨停买不进）。

### E2 卖出执行
止损/止盈触发时刻，用**触发那根 5m 的 close** 替代「假设按触发价成交」。分：开盘卖 / VWAP 卖 / 尾盘卖。

### E3 降换手过滤（用 5m 提升信号质量）
在 T+1 前 N 根 5m（如 6 根 = 开盘 30min）判定：
- 开盘 30min 即跌破入场价 2% → 放弃；
- 量能塌陷（前 30min 量 / 昨日同时段量 < 0.6）→ 放弃。
统计：过滤掉的笔数、这些笔的事后净超额、剩余笔的净超额变化。

### E4 组合层回测
E1+E2+E3 最优组合，输出 NAV / 最大回撤 / 夏普 / 年换手次 / 成本占毛 alpha 比，与 C0 对照。

## 7. 偏差预检清单（逐条打勾）

| # | 偏差 | 防护 |
|---|---|---|
| 1 | 5m 未来数据 | 信号 T 日收盘；成交只用 T+1 起 5m |
| 2 | VWAP 泄漏 | 仅同日 5m 聚合 |
| 3 | participation 失真 | 委托额 ÷ 当日该股 5m 日内成交额 |
| 4 | 不可能成交价 | 限价组逐根扫「最高价 ≥ 委托价」；TWAP 组判「该窗成交量 ≥ 委托量」 |

| 6 | 5m↔日线一致性 | 抽 20 只核对 Σ5m.amount ≈ 日线 amount |
| 7 | 小样本（仅 10 个月） | 报 t + bootstrap 97.5% CI |
| 8 | 执行参数过拟合 | 前半段选参、后半段验证，标「探索性」 |
| 9 | 比较单位 | 统一 bp/笔，禁混用组合 NAV 与单笔 bp |
| 10 | 成本一致性 | 所有组同一成本模型，只改成交价 |

## 8. 验证关卡（SOP §5 裁剪版）

5. **止损含成本对照**仍成立（毛口径）。

## 11. 实验结果（2026-10-14）

### 11.1 前置发现：`bars_1d` 重复行事故（项目级）

跑 E1 时发现 `bars_1d` 存在约 **42.8 万组重复 `(asset_code, trade_date)`**（2020–2026 全历史），
每组 2 行、`ts` 分别 **00:00 与 15:00**（source 全 `qmt`）。

**这不是"多算一遍"**：重复行使 `rolling(20/60)` 窗口塞进同一天两遍 → 均线/量指标失真 →
**信号集合本身改变**。已清洗（删 374,954 行，备份 `bars_1d_dup15_bak_20261014`），
总行数 12,829,526 → **12,454,572**；残留重复仅 index/sector_index，不影响股票回测。

→ **2020–2026 全部基于 `bars_1d` 的回测结论须重校。**

### 11.2 E0 重跑（干净数据）→ L4 前提被推翻

| 信号 | 污染前毛超额 | **清洗后毛超额** | 清洗后 0.25% |
|---|---:|---:|---:|
| F4 回踩MA20 | +13.00bp (t=+3.45) | **−7.29bp (t=−1.87)** | −32.29bp |
| S2 突破 | +13.05bp (t=+2.51) | **−7.17bp (t=−1.36)** | −32.17bp |
| F6 黄金坑 | +0.87bp (t=+0.15) | **−21.44bp (t=−3.71)** | −46.44bp |
| F5 首阴 | −3.58bp (t=−0.24) | **−6.05bp (t=−0.42)** | −31.05bp |

**2026 年全部信号毛超额为负**。"毛 alpha 还在、只被成本吃掉"是污染数据造成的假象
→ **L4 无法救活 F4/S2：信号本身已失效，不是执行问题。**

### 11.3 E1 成交方式（结论仍有效，且反直觉）

F4 同子样本 24,859 笔 / 全样本 35,762 笔，2026：

| 执行组 | 毛超额 bp | 净@0.25% |
|---|---:|---:|
| C0 开盘价（基线） | −9.5 | −34.5 |
| C1 全天 5m VWAP | −22.4 | −47.4 |
| C2a TWAP 30m | −17.8 | −42.8 |
| C2b TWAP 60m | −19.4 | −44.4 |
| C2c TWAP 120m | −20.8 | −45.8 |
| C3 缺口过滤 + VWAP | −32.0 | −57.0 |
| **C4 限价单（VWAP−20bp）** | **−0.8** | **−25.8** |

**结论**：对「超跌反弹」类信号，**T+1 开盘价已接近全天最优买点**；
延后成交（VWAP / TWAP）反而更贵（价格信号后一路上行）；TWAP 窗口越短越好。
**挂限价单（≈VWAP−20bp）比开盘价再省约 8bp**——这是本次 L4 唯一有价值的产出。

踩坑记录：① `amount/volume` 中 volume 单位是**手**，VWAP 必须 ×100；
② "过滤型"执行组有**样本选择效应**，必须用「同子样本」口径才可比。

### 11.4 裁定

**L4 命题证伪**（救活信号不成立），但沉淀一条通用规律：
> 超跌反弹/低吸类信号，**开盘价即最优成交价**；全天 VWAP 与长 TWAP 是负优化；
> 挂低于 VWAP 约 20bp 的限价单可再省 ~8bp。
