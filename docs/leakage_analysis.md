# 5步框架「真实摩擦」回测与泄漏分析

> 生成脚本：`tools/realistic_backtest.py`（基于 TimescaleDB `bars_1d` 全A日线，2021-01-01~2026-09-30，1393 交易日 / 5224 只）
> 目的：把「看大盘→选个股→看位置→买点→止损止盈」5步框架做成**可回测**的月频多头策略，并建模此前所有回测都忽略的真实执行摩擦，逐项量化"漏在哪"。

## 1. 这次建模了哪些之前没算的摩擦

| 摩擦 | 模型 | 之前回测是否计入 |
|---|---|---|
| 涨停买不进 | 次日开盘 `open ≥ 昨收×1.098` → 当天无法买入，信号作废 | ❌ 之前默认"开盘必成交" |
| 跌停卖不出 | 卖出日 `open ≤ 昨收×0.902` → 当天无法卖出，持仓顺延 | ❌ 卖出侧完全没过滤 |
| 额度漏动 | 单票下单额 > 当日成交额×5% → 只能买到上限(参与率截断) | ❌ 默认无限流动性 |
| 滑点 | Almgren 参与率模型 `impact_bp = 34.2×√参与率`，买卖双向 | ❌ 默认 0 滑点 |
| 手续费 | 佣金(可配,默认万2.5/最低5元) + 印花税 0.05%(仅卖) + 过户费 0.001%(双边) | ⚠ 部分脚本算了佣金，但漏印花税/过户费，且小账户最低5元未充分体现 |

策略本体（与之前一致）：大盘闸门定仓位(弱市空仓/震荡50%/强市80%) → 位置优先选股(贴近MA20支撑+20日动量正) → 次日开盘买入(剔除涨停/追高>3%) → 日线检查尾随止损(MA20下/5日低/≤-15%) + 两档止盈(+10% / 20日高)。

## 2. 三场景结果

| 账户 | 费率 | 流动性门槛 | 理想(无摩擦) | 真实(全摩擦) | 总泄漏 |
|---|---|---|---|---|---|
| **8万**（默认费率 万2.5/最低5元） | 万2.5+最低5 | 3000万/日 | 总 -0.7% / 年化 -0.1% | 总 **-6.3%** / 年化 -1.1% | **+6.0%** |
| **8万**（用户实际 万1/无最低） | 万1+无最低 | 3000万/日 | 总 -0.7% / 年化 -0.1% | 总 **-3.5%** / 年化 -0.6% | **+2.9%** |
| 500万（压力） | 万2.5+最低5 | 300万/日 | 总 -7.5% | 总 -12.9% | +6.2% |
| 5000万（压力） | 万2.5+最低5 | 300万/日 | 总 -7.6% | 总 -14.3% | +7.8% |

> 注：500万/5000万场景故意把流动性门槛降到300万以逼出"额度漏动"；你8万用的是3000万门槛，小账户流动性截断为0（反而能随时满仓买到）。

## 3. 泄漏点逐项拆解（这就是"漏的点"）

| 泄漏项 | 8万 | 500万 | 5000万 | 说明 |
|---|---|---|---|---|
| **涨停漏买** | 6次/288 | 6次 | 6次 | 信号发出但开盘即板，买不进（错过的涨幅未计入，是真实机会损失） |
| **跌停卖不出** | 5次 | 7次 | 7次 | 持仓被锁，极端日无法止损（之前的回测把这种日算成"无涨跌"抹掉了亏损） |
| **额度漏动** | **0** | **0** | **1045万** | 8万/500万碰不到5%上限；机构级才显形（与"liquid500池上限约1000万"结论一致） |
| **滑点** | 29元 | 2.1万 | 63万 | 随账户规模上升，参与率模型 |
| **手续费** | 3105元(默认) / **873元**(万1) | 11万 | 110万 | 默认费率下8万**主导泄漏**(~3.9%本金,最低5元吃死小仓位); **用户实际万1/无最低仅873元≈1.1%本金，已不是死穴** |

## 4. 与之前回测的对比——之前到底漏了什么

- `strategy_pnl_ratio.py` / `etf_backtest.py` 默认"开盘/收盘必成交、零冲击" → 把涨停买不进、跌停卖不出、滑点、最低5元佣金全部当0，**结果系统性偏乐观**。
- 本回测显示：即便框架**理想无摩擦**也只有 -0.7%（8万口径），说明**框架本身没有正 alpha**；之前的"看起来还行"主要是没扣真实成本。
- 8万真实 -6.3%（默认费率）中，**手续费3105元占绝大部分**；但用户实际费率为**万1、无最低5元**，重跑后真实 -3.5%、手续费仅873元（≈1.1%本金）——**佣金已不是死穴**。滑点/涨停跌停是次要但真实的风险（跌停锁仓在尾部行情会放大亏损）。

## 5. 诚实结论

1. **5步框架 = 纪律工具，不是盈利策略**：横截面选股(位置优先+动量)在这段样本里没有稳定超额，理想都微亏。它的最大价值是**把盘感变成可核对、可执行的价位与仓位**，而非保证赚钱。
2. **费用不是你8万的死穴（已纠正）**：之前默认"最低5元佣金"算出3105元≈3.9%本金是主导泄漏；但你实际费率**万1、无最低5元**，重跑后手续费仅873元≈1.1%本金，且万1下总泄漏从+6.0%降到+2.9%。真正约束8万的是**框架本身无正alpha**（理想都-0.7%），而非佣金。降换手/换ETF仍有意义，但紧迫性已大幅降低。
3. **额度漏动是机构级问题**：你8万完全不用操心流动性截断；只有到千万级以上，单票下单才会被日成交额卡住（这部分泄漏在5000万场景是1045万）。
4. **涨停/跌停是真实执行风险**：6次买不进+5次卖不出，虽然占比小，但尾部行情里"卖不出"会让你在暴跌日硬扛，必须当成策略成本。

## 6. 下一步建议（按杠杆排序）

- **P0（对你8万最实际）**：把月频改季频/半年度，或只在"大盘强+个股破位"时动，进一步降换手；或用ETF替代个股（免印花税、费率更低，见 `etf_vs_stock_backtest.html`）。万1费率下佣金已非主要矛盾，重点应回到"框架是否有alpha"本身。
- **P1**：把跌停卖不出做成"次日集合竞价挂跌停价排队"的保守成交假设，重算尾部风险。
- **P2**：机构级才需要解决额度漏动（VWAP拆单 / 换更大流动性池）。
- 框架若想证明有 alpha，须换**行业+市值中性化**后的选股（之前分池实验已证明当前信号是风格/流动性因子，非个股alpha）。
