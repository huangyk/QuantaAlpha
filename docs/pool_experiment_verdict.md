## 零、先更正上一份文档的方向错误

`docs/candidate_factors_verdict.md` 里写的「test 期毛 alpha **+8.94%/年**」**符号是反的**。
分位组代码用了 `rank(method='first')`（默认升序），**label 0 其实是分数最低组**，
我却把它标成 D1=最高分，算出的 `D1−D10 = +3.55bp` 实际是「最低组 − 最高组」。

**更正：test 期真实毛 alpha = −3.55 bp/日 = −8.94%/年（负的）。**
所以那个信号不只是"成本太高"，**在 2025-2026 test 期本身就是反向的**。

同一次修正也适用于本轮的全部分位组数字（下面已用 `ascending=False` 重算）。

## 二、三个决定性发现

### 发现 1：IC 与「小盘程度」严格单调正相关 —— 这不是个股 alpha，是风格因子

```
小盘后500  0.0809  >  中盘 0.0433  >  大盘 0.0273  >  可交易池 0.0102
```

信号越强，池子越小、越没流动性。**它在「小盘低流动性」这个风格上做文章，不是在选个股。**

### 发现 2：一旦加上流动性约束，信号立刻消失

P5（可交易，日均成交额 ≥3000 万）IC 只有 **0.0102**，且 **2025 年还是负的（−0.0056）**。
也就是说：**所有 alpha 都藏在买不进、卖不出的那一端。**

### 发现 3：毛 alpha 再大也提取不出来（分组不单调）

P4 毛 alpha 高达 **+305%/年**，但净超额只有 **+0.15%**。
原因：**六个池的十分位组全部不单调**，alpha 集中在中部分布，持 Top-K 拿不到。
这是「正的 IC ≠ 可提取的 alpha」最硬的一次证明。

## 三、结论

**换池不能解决问题。** liquid500 的问题不是池子选错了，而是：
1. 这个信号本质是**风格/流动性因子**，不是个股选择能力；
2. 它的强度与不可执行程度成正比 —— 越没流动性越强；
3. 加上任何可执行约束（流动性、单调性）后，它就归零。

### 现有池子上的定性论断
| 结论 | 证据 |
|---|---|
| 池等权仍是最强策略 | P0 liquid500 基准 +107.23%/年（2020-2026） vs 所有策略净超额 ≈0 |
| 小盘/低流动性长期跑赢 | P4 小盘基准 +2.85% vs P0 liquid500 +107.23%（组成差异） |
| 任何选股增量都提取不出来 | 6 个池的净超额全部落在 −0.25% ~ +0.42% |

### 下一步该怎么走（不再挖因子）
1. **接受「池等权 + 低成本」是当前最优解**，把工程做扎实：流动性配额、拆单、开盘买早盘卖。
2. **若一定要找 alpha，必须离开这个数据维度**：
   - 补**行业分类 + 总股本/流通市值**做真正的中性化（当前无行业/市值数据）
   - 补**涨跌停价 + ST 标记**做更真实的价格约束
   - 这些是 P2/P2 数据缺口，不是再算一遍 IC 能解决的。
3. **换更强的因子维度**：日内 5min 已试过（证伪）；可考虑分钟级日内形态、舆情/资金流（TimescaleDB 里没有）。

## 四、本轮踩到的三个坑（已修，写进铁律）

1. **分位组方向**：`pd.qcut(x.rank(method='first'))` 默认升序 → label 0 是**最低**分。
   必须写 `ascending=False` 才是 D1=最高分。**曾因此把 −8.94% 写成 +8.94%。**
2. **因子算前必须 ffill 补停牌价**：未补价时 score 只有 22% 有效、每日仅 11 只
   （500 只池里），样本严重偏差，结论完全失真。补价后覆盖率 4291/5364 = 80%。
3. **`Series.to_frame('r').stack()` 的层级名**：列名会变成 0 而非 instrument，
   与 `DataFrame.stack()` 对齐后全 NaN。IC 计算改用**按日循环**更稳。
