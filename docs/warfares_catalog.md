## A. 通达信 6 战法（源：`reference/tdx_strategies/tdx_warfare_modular_design.md`）

原子因子 F1–F10 见 §B。每战法 = 过滤(M1)+信号(M2)+确认(M3) 组合。

### ✅ 战法2 均线回踩低吸（首推，已验证有边）
- 定义：M1=`F3`(MA20>MA60 多头过滤) → M2=`F4`(回踩MA20且金叉) → M3=`F2`(放量确认)
- **F4 信号（事件驱动精确版，守 T+1 对齐）**：
  `距MA20<3% 且 收>MA20 且 昨收<=昨MA20`（金叉）；T日收盘出 → **T+1 开盘买** → 最早 T+2 收盘出
- 出场：**≤8% 止损 / +10% 止盈 / 最长20日**
- **状态：✅ 真实择时边（修订旧"≈0"判决）**
  - 全 A 事件驱动（2020–2026）：**+22.8bp/笔 (t+14.6)**，市值中性后更强(+24bp) → **非小盘风格**
  - **比随机入场(同套止损)多 +19bp/笔** → 真择时 alpha
  - **regime-dependent**：2020–2022 强年跑赢随机 +28~+43bp；2023 震荡年失灵(−6bp 跑输)；2024 微负
  - **必须带 ≤8% 止损**（无止损高度环境依赖，震荡年变负）
- 证据：`docs/dixi_fullpanel_verdict.md`；脚本 `tools/dixi_fullpanel_backtest.py`
- 用法：作**入场触发器**（回踩MA20金叉才建仓）+ 严格止损，小仓位试；或每日取 F4 前 N 只的小组合

### ✅ 战法5 龙回头（已验证有边，稀有）
- 定义：M1=曾是龙头 → M2=`F7`(60日曾涨>25%且回踩MA20金叉MA10) → M3=放量转强
- **F7 信号**：`DELAY(TS_MAX(C,60),20)/TS_MAX(C,60) > 1.25`（60日前曾比今高25%+，即曾领涨）且 `C>MA20` 且 `C>MA10` 且 `VOL>MA5*1.3`
- **状态：✅ 真实择时边（稀有信号）**
  - 全 A 事件驱动：**+19.5bp/笔 (t+2.1)**，市值中性 +26.4bp(t+2.85)
  - 但信号稀少（6.6K 笔/7年 ≈ 950笔/年）→ 可作**增强/稀少机会**，不宜作主策略
- 证据：`docs/dixi_fullpanel_verdict.md`

### ❌ 战法1 突破放量主力流入共振（证伪）
- 定义：M1=`F3` → M2=`F1`(突破)+`F2`(放量)+`F9`(主力近似) → M3=`F10`(板块强,外部依赖)
- 状态：❌ `F1 突破` IC≈0 跑输同池等权；`F9` 主力流是 L2 近似无信息；组合无 alpha
- 证据：`docs/factor_scorecard.md` §4（tdx_warfare146：F1/F6/F8/F9 证伪）

### ❌ 战法3 首阴/开板低吸（证伪）
- 定义：M1=前日涨停 → M2=`F5`(首阴) → M3=`F8`(弱转强确认)
- **F5 信号**：`昨收/前收>1.095(昨涨停) 且 今收<昨收 且 VOL>MA5*1.5`
- 状态：❌ 事件驱动 **−7.0bp/笔 (t−1.07)**，市值中性 −1.4bp → **比随机还差**，不可用
- 证据：`docs/dixi_fullpanel_verdict.md`

### ❌ 战法4 黄金坑（证伪：无择时）
- 定义：M1=前期横盘 → M2=`F6`(黄金坑) → M3=`F2`(收回确认)
- **F6 信号**：`TS_MIN(C,20) < MA60*0.93(20日新低破MA60*0.93) 且 C>MA20(收回) 且 VOL>MA5*1.5`
- 状态：❌ 事件驱动 **+1.96bp/笔 (t+0.86)** ≈0 → 无择时，仅止损机制收益；不可当选股信号
- 证据：`docs/dixi_fullpanel_verdict.md`

### ❌ 战法6 分歧转一致（弱转强，证伪）
- 定义：M1=— → M2=`F8`(弱转强/日内) → M3=收高位
- **F8 信号（日内）**：`开<昨收 且 收>昨收 且 VOL>昨量*1.2 且 收>开`（低开高收放量）
- 状态：❌ `F8 弱转强` IC≈0 跑输同池等权
- 证据：`docs/factor_scorecard.md` §4（tdx_warfare146）

## B. 原子因子速查（M2 零件，AlphaAgent 表达式，无未来函数）

| 因子 | 语义 | 表达式（Qlib 语法） | 验证状态 |
|---|---|---|---|
| F1 趋势突破 | C创N日新高且站上MA60 | `GT($close, TS_MAX(DELAY($close,1), N)) && GT($close, SMA($close,60))` | ❌ IC≈0 |
| F2 放量 | VOL>MA5*1.5 且>昨量 | `$volume > SMA($volume,5)*1.5 && $volume > DELAY($volume,1)` | ⚠️ 无信息(仅确认用) |
| F3 均线多头 | MA20>MA60 | `SMA($close,20) > SMA($close,60)` | ⚠️ 过滤用(战法2 M1) |
| **F4 回踩均线** | 距MA20<3%且金叉 | `ABS($close-SMA($close,20))/SMA($close,20)<0.03 && $close>SMA($close,20) && DELAY($close,1)<=DELAY(SMA($close,20),1)` | ✅ 真实择时边 |
| F5 首阴 | 昨涨停今收阴放量 | `GT(DELAY($close,1)/DELAY($close,2),1.095) && LT($close,DELAY($close,1)) && GT($volume,SMA($volume,5)*1.5)` | ❌ 比随机差 |
| F6 黄金坑 | 20日新低<MA60*0.93收回 | `LT(TS_MIN($close,20),SMA($close,60)*0.93) && GT($close,SMA($close,20)) && GT($volume,SMA($volume,5)*1.5)` | ❌ 无择时 |
| **F7 龙回头** | 60日曾涨>25%回踩金叉 | `GT(DELAY(TS_MAX($close,60),20)/TS_MAX($close,60),1.25) && GT($close,SMA($close,20)) && GT($close,SMA($close,10)) && GT($volume,SMA($volume,5)*1.3)` | ✅ 真实边(稀有) |
| F8 弱转强(日内) | 低开高收放量 | `LT($open,DELAY($close,1)) && GT($close,DELAY($close,1)) && GT($volume,DELAY($volume,1)*1.2) && GT($close,$open)` | ❌ IC≈0 |
| F9 主动资金(≈主力) | 价升量增(L2近似) | `GT($close,$open) && GT($close,SMA($close,5)) && GT($volume,DELAY($volume,1)*1.2)` | ❌ 近似无信息 |
| F10 板块强 | 板块3日主力净流入>0 | 需板块级资金(外部依赖) | — 数据缺口 |

> 无 `CROSS` 内置，用 `A>B && DELAY(A,1)<=DELAY(B,1)` 组合。L2 主力流缺失 → F9/F10 不可靠。

## C. 其它策略/战法（非通达信，项目全期结论）

### ✅ ETF 跨资产轮动（absmom / 七星高照）— 唯一存活主策略
- 信号：200日SMA + 逆波动率，月度调仓；股票↔债券/现金切换（真防守）
- 结果：底盘满仓 ~10%/Sharpe1.03/回撤−9.4%（年~12次）；60%暴露档 ~5.5%/1.03/−4.8%（低回撤）
- **股票单资产池所有路线均败，ETF 跨资产完胜**（详见 `docs/stock_verdict.md`）
- 部署：QMT 粘贴版 `docs/absmom_qmt_paste.txt`（用户手动粘贴，勿改 QMT 目录）
- 证据：`docs/strategy_absmom.md` / `docs/qixing_etf_verdict.md` / `docs/etf_portfolio_verdict.md`

### ⚠️ 低波动异象 — 真实 rank 信号，但不可变现（仅防御过滤器）
- 行业+市值中性 IC +0.0312 (t+7.35) → 真信号；但正确方向多空/单多**全负**（−29.7%~−8.6%）
- 机制：A股高波动小盘有极厚正右尾，rank 信号只在中位数有效、均值被吞噬
- 用法：仅作**防御降回撤过滤器**（大盘低波动回撤仅−4.0%），非 alpha 来源
- 证据：`docs/lowvol_true_neutral_verdict.md` / `docs/factor_scorecard.md` §8

### ❌ 股票单资产路线（全部证伪，不再投入）
- 个股趋势跟随(40周SMA+逆波动)：−3.27%/−0.14/−82.6%（比等权还差）
- 市场级择时(宽度信号 股票↔现金)：训练期 Sharpe1.33，测试期 +1.68%/0.155 远输长持 → 过拟合
- ML/DL 周频择时(gbm/xgb/mlp)：全部≈恒定暴露比例，未超恒定40%空基准(Sharpe0.378) → 无 alpha
- 飞龙多因子：IC≈0，无单调，−11.44%/年 vs 同池等权
- 证据：`docs/stock_verdict.md` / `docs/feilong_v2_verdict.md`

## D. 用战法的铁律（每次迭代必查）

1. **信号-收益对齐**：T日收盘出分→收益从 T+1 起（买T+1、卖T+1+h）；`close.shift(-h)`=未来函数。IC 高得离谱先查对齐。
2. **基准同口径**：同池等权；沪深300 只能作环境参照（管中小盘池方向会反）。
3. **判 alpha 看分位组单调性** + 市值中性；不只看 top-K。
4. **低吸/买回调必须带 ≤8% 止损**（否则统计上自杀）；加了止损期望才稳健正。
5. **防过拟合三重测**：walk-forward 隔离 / 参数成簇 / 成本敏感（含市场冲击）。
6. **数据完整性**：`bars_1d` 可交易历史 2020–2026（2011–2019 过稀零成交；2025–2026 回填未完）→ 任何"全A 16年"结论须先查数据密度。
7. **仅 TimescaleDB，禁默认 akshare**（用户硬规则）。
