## A. 通达信 6 战法（源：`reference/tdx_strategies/tdx_warfare_modular_design.md`）

原子因子 F1–F10 见 §B。每战法 = 过滤(M1)+信号(M2)+确认(M3) 组合。

### ⚠️ 战法2 均线回踩低吸（下调：边=小盘风格+止损，非选股 alpha）
- 定义：M1=`F3`(MA20>MA60 多头过滤) → M2=`F4`(回踩MA20且金叉) → M3=`F2`(放量确认)
- **F4 信号（事件驱动精确版，守 T+1 对齐）**：
  `距MA20<3% 且 收>MA20 且 昨收<=昨MA20`（金叉）；T日收盘出 → **T+1 开盘买** → 最早 T+2 收盘出
- 出场：**≤8% 止损 / +10% 止盈 / 最长20日**
- **状态：⚠️ 由 ✅ 下调（2026-10-13 三口径复核，见下）**
  - 旧结论（等权基准，2020-2026）：+22.8bp/笔 (t+14.6)，市值中性后 +24bp → 判"真实择时 alpha"
  - **修正：等权基准被妖股绑架**。同池等权 2024 +36.3% / 2025 +47.7%，
    而中位数股 -1.1% / -17.1%、最高 amount 十分位 2025 +663.6%
    （`tools/_benchmark_sanity.py`）。
  - **同 amount 十分位口径（最严基准）** 2020-2024 全期 +36.53bp (t=+20.76)，
    但：① **成本 0.5% 即降到 +11.53bp、1% 转负 -38.47bp**；② 逐年 2020 -13.1 /
    2021 +70.5 / 2022 +112.5 / 2023 +27.7 / 2024 -11.6（2 年负，摆动 >120bp）；
    ③ **规模分档单调**：最低 amount 档 +296bp → 最高 amount 档 **-562bp**；
    ④ 无止损对照 -68.15bp → 正超额依赖止损机制。
  - **OOS(2025-2026) 同档口径 -12.23bp (t=-4.06)**，去极值 -1.89bp → **边已消失**。
  - 机制判定：**"小盘/低成交额风格 + 止损"的组合效应，不是个股 alpha**。
    最低成交额池 2025-2026 崩塌（中位数基准年化 -22%）使该边归零。
- 证据：`docs/dixi_fullpanel_verdict.md`（旧，等权口径，**结论已修订**）；
  `tools/is_2020_2024_tribench.py`、`tools/f4_robustness_check.py`、
  `tools/oos_2025_tribench.py`、`tools/_benchmark_sanity.py`
- 用法：**不再作为 alpha 来源**。仅可作"低成交额小盘池 + 严格止损"的短线触发器试仓，
  且必须接受成本翻倍即无边的现实。要重新启用需先看到最低成交额池恢复。


### ✅ 战法5 龙回头（已验证有边，稀有）

- **状态：⚠️ 由 ✅ 下调（2026-10-13 三口径复核）**

    中位数口径的正值（+121.96/+110.83）同样是小盘风格效应。
  - 信号依旧稀少（2020-2024 仅 6,783 笔），且同档口径为负 → **不再作为可用边**。
- 证据：`docs/dixi_fullpanel_verdict.md`（旧，**结论已修订**）；

## B. 原子因子速查（M2 零件，AlphaAgent 表达式，无未来函数）

| 因子 | 语义 | 表达式（Qlib 语法） | 验证状态 |
|---|---|---|---|
| F1 趋势突破 | C创N日新高且站上MA60 | `GT($close, TS_MAX(DELAY($close,1), N)) && GT($close, SMA($close,60))` | ❌ IC≈0 |
| F2 放量 | VOL>MA5*1.5 且>昨量 | `$volume > SMA($volume,5)*1.5 && $volume > DELAY($volume,1)` | ⚠️ 无信息(仅确认用) |
| F3 均线多头 | MA20>MA60 | `SMA($close,20) > SMA($close,60)` | ⚠️ 过滤用(战法2 M1) |
| F4 回踩均线 | 距MA20<3%且金叉 | `ABS($close-SMA($close,20))/SMA($close,20)<0.03 && $close>SMA($close,20) && DELAY($close,1)<=DELAY(SMA($close,20),1)` | ⚠️ **由✅下调**：同档口径仅低成交额档为正，成本翻倍归零，OOS 转负 |
| F5 首阴 | 昨涨停今收阴放量 | `GT(DELAY($close,1)/DELAY($close,2),1.095) && LT($close,DELAY($close,1)) && GT($volume,SMA($volume,5)*1.5)` | ❌ 比随机差；同档口径 -104.64bp |
| F6 黄金坑 | 20日新低<MA60*0.93收回 | `LT(TS_MIN($close,20),SMA($close,60)*0.93) && GT($close,SMA($close,20)) && GT($volume,SMA($volume,5)*1.5)` | ❌ 无择时；同档口径 -72.63bp，三口径全负 |
| F7 龙回头 | 60日曾涨>25%回踩金叉 | `GT(DELAY(TS_MAX($close,60),20)/TS_MAX($close,60),1.25) && GT($close,SMA($close,20)) && GT($close,SMA($close,10)) && GT($volume,SMA($volume,5)*1.3)` | ❌ **由✅下调**：同档口径 -83.31bp，OOS -127.52bp |
| F8 弱转强(日内) | 低开高收放量 | `LT($open,DELAY($close,1)) && GT($close,DELAY($close,1)) && GT($volume,DELAY($volume,1)*1.2) && GT($close,$open)` | ❌ IC≈0 |
| F9 主动资金(≈主力) | 价升量增(L2近似) | `GT($close,$open) && GT($close,SMA($close,5)) && GT($volume,DELAY($volume,1)*1.2)` | ❌ 近似无信息 |
| F10 板块强 | 板块3日主力净流入>0 | 需板块级资金(外部依赖) | — 数据缺口 |

> 无 `CROSS` 内置，用 `A>B && DELAY(A,1)<=DELAY(B,1)` 组合。L2 主力流缺失 → F9/F10 不可靠。
> **★ 2026-10-13 注**：上表 F4/F5/F6/F7 的"验证状态"已按**同 amount 十分位口径**更新
> （等权口径被妖股绑架，不可用）。F4/F6/F7 的正超额集中在最低成交额档，
> 属小盘风格而非选股 alpha。详见 `docs/warfares_catalog.md` §A 与铁律第 0 条。

## D. 用战法的铁律（每次迭代必查）

0. **★超额必须三口径并列（2026-10-13 新增，最高优先级）**：
   等权 / 中位数 / 同规模档（`amount` 十分位）。**只看等权基准 = 被妖股绑架**：
   同池等权 2024 +36.3% / 2025 +47.7%，而中位数股 -1.1% / -17.1%。
   若正超额集中在极端规模档 → 判为**风格**而非 alpha。
0b. **★★禁止用「每日同期排名」分档做基准或宇宙（2026-10-13 第二轮新增，未来函数级）**：
   用"**当天** amount 排名分十档"是**因果倒置**——当天大涨本身导致成交额暴增，
   所以当天成交额排名包含当天收益信息。实测每日分档下
   decile9 日均收益 **+48.55bp**、NAV 终点 **7130x**、年化 **+231%**（荒谬）。
   **必须改用滞后 60 日平均 amount 排名**（用上一日值），档位才是稳定的股票属性。
   滞后口径下 decile0~9 年化分别为 +29.26%/+11.83%/…/+6.79%/…/+0.01%（合理）。
   → 本项目**所有**"分市值档/分成交额档"的历史结论都受此污染，须用滞后口径复核。
1. **信号-收益对齐**：T日收盘出分→收益从 T+1 起（买T+1、卖T+1+h）；`close.shift(-h)`=未来函数。IC 高得离谱先查对齐。
2. **基准同口径**：同池等权；沪深300 只能作环境参照（管中小盘池方向会反）。
3. **判 alpha 看分位组单调性** + 市值中性；不只看 top-K。
4. **低吸/买回调必须带 ≤8% 止损**（否则统计上自杀）；加了止损期望才稳健正。
   （2026-10-13 复核：F4 带止损 +36.53bp vs 无止损 -68.15bp，同档口径）
5. **防过拟合三重测**：walk-forward 隔离 / 参数成簇 / 成本敏感（含市场冲击）。
   （2026-10-13 复核：F4 成本 0.25%→+36.53bp、0.5%→+11.53bp、1%→-38.47bp，**成本翻倍即归零**）
6. **数据完整性**：`bars_1d` 可交易历史 2020–2026（2011–2019 过稀零成交；2025–2026 回填未完）→ 任何"全A 16年"结论须先查数据密度。
   **★ `float_shares`/`turnover_rate` 在 2025-02~2026-03 共 14 个月整段 NULL**
   （2026-04/05/07 混合段）→ 该区间规模一律用 `amount`（非空率 100%）。
   任何带 `float_shares.notna()` 的脚本会**静默丢掉这 14 个月**，必须排查。
7. **仅 TimescaleDB，禁默认 akshare**（用户硬规则）。
