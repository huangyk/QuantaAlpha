QuantaAlpha 交易计划 · 操作手册

生成日期 2026-10-08 · 基于 2020–2026 全样本严格口径验证 · 项目根目录 docs/trading_plan.html

⚠️ 先说最关键的实话：我们挖了飞龙 / 战法2 / 5min 低波动 / 短期反转 / 换手率因子等十几个信号， 在「真实交易成本 + 信号-收益正确对齐」口径下 全部证伪。没有任何一个横截面选股因子能稳定跑赢。 下面这份计划不是"一年赚 30–40%"的秘籍，而是 唯一经得起验证的东西：低换手池等权持有—— 它本质是「买一篮子中小盘并持有」的 beta/风格策略，不是 alpha。

飞龙 V2（三因子+大盘闸门）❌ 无截面 alpha，闸门方向反同池基准下 −11.4%
战法2（均线回踩低吸）❌ 因子内部自相矛盾，样本外全负测试期 −50%

关于「+19.85%」的澄清：早期报告里的 liquid500 +19.85% 是 幸存者偏差—— 那个池是按 2026 年的流动性挑的前 500 只，等于「提前知道谁活下来」。不能用作预期， 只能当理论上限参考。无偏口径（每月用当时数据重选）只有约 +2.5%/年，且 2021 年起转负。

§2 交易计划（照着做）

1选池：全 A 按 60 日成交额中位数排序，取 流动性中后段（第 1001~3000 名）。 修正池构建 bug 后证实：低流动性段长期跑赢（中后段 +2.89% > Top500 +2.02%）。
2剔除（建仓日）：① 数据历史 < 500 交易日（近似剔除次新股）； ② 涨停开盘（买不进）；③ 停牌/无成交；④ 若当天全市场更新股票 < 候选一半，跳过该日（数据残缺）。
3建仓时点：每月首个交易日，09:30 集合竞价买入（实测比当日 VWAP 便宜 12bp）。 避开 10:00 与 13:05（当日最贵）；拆单到全天（集中单时段冲击贵 3 倍）。
4权重：等权；单票 ≤ 5%；流动性配额 w ≤ 2% × 日成交额 / 账户（防冲击）。 不划算的高价股因 100 股取整会自然落到 0 股——属正常残差。
5持有：永久持有，不择时、不选股、不调仓、不用大盘闸门。 所有「择时/再平衡/风格开关」增强实测都是负超额——不动就是最好的动作。
6卖出：仅三种退出——退市、ST 风险、或单票流动性枯竭（日成交额长期为 0）。 正常波动 不止损（A 股跌停日无法止损，这是接受的尾部代价）。
7容量：1000 万账户可落地；经成交量单位修正后，数亿资金也能执行（单票日成交额中位数约 4.3 亿）。

§3 怎么用（部署到 QMT / Ptrade）

研究代码与下单解耦，本计划是「人工抄单」模式（最稳，不依赖自动交易授权）：

  1. 在 QMT 正常机器上（或沙箱连 TimescaleDB）运行下单清单生成器： 
    cd D:\qqmt\QuantaAlpha
python tools/make_order_list.py                 # 默认 1000万 / 流动性 1001~3000
python tools/make_order_list.py --account 5e6 --lo 1001 --hi 1500
    产出 data/results/order_list_YYYYMMDD.csv（列：代码 / 权重 / 参考价 / 股数 / 金额）。
  2. 打开 CSV，按「股数」列在 QMT 交易终端手动下达买入单（等权、09:30 集合竞价）。
  3. 每月首个交易日重复一次：卖出现在清单里没有的、买入新清单里有的（换手极低，多数月份几乎不动）。
  4. 实战参数调节：1000 万账户建议把范围收到 --lo 1001 --hi 1500（约 500 只，每票 ~2 万，100 股可成交）； 1770 只版本每票仅 ~5600 元，高价股会 rounding 成 0 股、现金闲置偏多。
✅ 已用 2026-09-30 实测跑通：筛出 1770 只可买，等权，占用 827 万（1000 万账户）。清单真实可读。

§4 怎么验证（回测 + 实盘监控）

A. 回测复跑（验证策略本身没坏）

python tools/strategy_final.py        # 统一口径重算各池 buy&hold
# 看 data/results/strategy_final.csv：按「净年化」排序

及格线：中后段流动性净年化 > 同池等权基准（约 +2.5%）； 不及格：若某一层明显转负或跑输基准 > 2pp，说明风格又切换，暂停加仓。

B. 实盘监控（验证你执行得对）

指标怎么看判读
每日净值账户市值 / 期初对比同池等权基准（可用 strategy_final.csv 的层收益近似）
最大权重漂移单票权重 − 5% 上限超过则说明某票暴涨，考虑减回上限（非强制）
最大回撤净值 / 历史峰值 − 1全期约 −11%~−18%；单段更深属正常
月度换股率当月买卖金额 / 总市值应 < 5%（高换手会吃掉收益，是头号杀手）
验证铁律：判 alpha 看分位组单调性，不只看 top-K 超额；基准必须同池口径； IC 高得离谱先查信号-收益对齐（未来函数是本项目头号造假源）。这三条有任何一条被违反，结论作废。

§5 风险提示与下一步

  • 这不是 alpha：预期年化约 +2.5%，2021 年后样本为负。把它当「底仓/市场敞口」，别当印钞机。
  • 风格切换是最大风险：低流动性占优在 2021 后减弱，若市场转大市值风格，本计划会跑输。
  • 真正的破局方向（尚未验证）：补行业+市值+涨跌停/ST 做真中性化、换成熟成分股池、 在执行层降换股率。当前无任何经验证的 alpha，任何新因子须先显著跑赢同池等权。
