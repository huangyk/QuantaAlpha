⚠️ 先说最关键的实话（请你先读这段再决定用不用）： 所有横截面选股因子（飞龙 / 战法2 / 5min / 反转 / 换手率）在严格口径下 全部证伪。 下面这份是 唯一能算出正期望的东西：流动性中后段池「月再平衡」。 它不是"一年 30–40%"的秘籍，是 盈亏比 1.13、胜率 57%、期望月收益 +1.24% 的薄alpha策略， 且 2017–2020 段实际亏 −2.8%（胜率掉到 48%）。能交易、有正期望，但薄且吃市场阶段。

§0 核心指标：盈亏比（你要的就是这个）

策略：每月首个交易日按「过去 60 日成交额」重选流动性第 1001~3000 名等权买入，持有到次月首再平衡。 每一个再平衡周期 = 一次「交易回合」，盈亏比按回合统计。

怎么读盈亏比 1.13：每笔盈利平均赚 6.33%/月，每笔亏损平均亏 5.61%/月。 盈亏比 低于 2.0 的健康线——本策略靠「胜率 57%」而非「赚多赔少」吃饭。 一旦胜率掉到 50% 以下（如 2017–2020），整体就亏。所以它是薄alpha，不是稳赚。 最大回撤 −52.6% 意味着你要能扛住账户腰斩，否则撑不到正期望兑现。

§1 战法总结：到底有没有用

被验证的对象结论真实年化（修正后口径）
飞龙 V2（三因子+大盘闸门）❌ 无截面 alpha，闸门方向反同池基准下 −11.4%
战法2（均线回踩低吸）❌ 因子内部自相矛盾，样本外全负测试期 −50%
5min 低波动族❌ 分组不单调（U 型）净超额 +5.6%（t=0.42 不显著）
短期反转+量能退潮❌ 正 IC 但提取不出净超额 +8.9%（t=0.42）
换手率因子❌ 过 OOS IC 检验但仍不可变现策略超额 −0.37%（t=−0.84）
流动性中后段 · 月再平衡✅ 唯一正期望+11.5%（全期）/ 段内 −2.8%~+36%
（对照）流动性中后段 · 买入持有保守版，不轮动+2.5%（全期，2021 后转负）
为什么月再平衡（+11.5%）比买入持有（+2.5%）高？ 买入持有只在第 1 个月吃到流动性溢价，之后篮子名称固化、不再代表「中后段」； 月再平衡每月把篮子轮回「当时流动性中后段」，持续重吃溢价。两者不是同一策略， 再平衡多出来的收益来自流动性轮动，不是某个选股 alpha。

§2 交易计划（照着做 · 月再平衡版）

1选池：全 A 按「过去 60 日成交额中位数」排序，取 第 1001~3000 名（流动性中后段）。 这是盈亏比 1.13、期望 +1.24%/月 的池。范围收到 1001~1500（约 500 只）更便于手动下单。
2剔除（建仓日）：① 上市 < 500 交易日（近似剔除次新）；② 涨停开盘（买不进）； ③ 停牌/无成交；④ 全市场更新股数 < 候选一半则跳过该日（数据残缺）。
3建仓时点：每月首个交易日 09:30 集合竞价买入（实测比当日 VWAP 便宜 12bp）。 避开 10:00 与 13:05；拆单到全天（集中单时段冲击贵 3 倍）。
4权重：等权；单票 ≤ 5%；流动性配额 w ≤ 2% × 日成交额 / 账户。 1000 万账户建议 --lo 1001 --hi 1500（约 500 只，每票 ~2 万，100 股可成交）。
5再平衡：每月首个交易日卖出现在清单没有的、买入新清单有的。 月均换手约 16% → 500 只约 80 卖 + 80 买 = 160 笔/月，手动可承受。
6退出：退市 / ST / 单票流动性枯竭（日成交额长期为 0）。正常波动不止损 （A 股跌停日无法止损，是接受的尾部代价；靠 −5% 单票上限 + 分散控回撤）。
7容量：1000 万可落地；成交量单位修正后数亿也能执行（单票日成交额中位约 4.3 亿）。

§3 怎么用（部署到 QMT / Ptrade 抄单）

  1. 在 QMT 正常机器上运行下单清单生成器（按最新交易日选池）：

§4 怎么验证（回测 + 实盘监控）

A. 回测复跑

python tools/strategy_pnl_ratio.py     # 重算盈亏比/胜率/回撤 → data/results/pnl_ratio.csv
python tools/strategy_final.py         # 统一口径各池 buy&hold → strategy_final.csv

及格线：P3 池（1001~3000）月再平衡净年化 > +5%、盈亏比 > 1.0、胜率 > 50%。 不及格：若某 3 年窗口胜率 < 50% 且年化转负，说明风格切换，暂停加仓（仿 2017–2020）。

B. 实盘监控

指标怎么看判读
每月回合收益月末市值 / 月初市值 − 1对照盈亏比表：盈利月应 ≈ +6.3%，亏损月 ≈ −5.6%
滚动胜率近 12 个月盈利月数 / 12< 50% 连续 3 月 → 预警，考虑减仓
最大回撤净值 / 峰值 − 1全期 −52.6%；若逼近 −40% 且不止损则检查篮子是否失真
月度换股率当月买卖金额 / 总市值应 ≈ 16%（过高说明池漂移太快，成本上升）

§5 风险与诚实边界（请务必读）

  • 盈亏比 1.13 偏低：健康线 ≥ 2.0。本策略靠胜率（57%）吃饭，胜率一掉到 50% 以下就亏（2017–2020 实证 −2.8%）。
  • 最大回撤 −52.6%：你能扛住账户腰斩吗？扛不住就别全仓，按能承受的回撤反推仓位（如只敢 −20% → 半仓）。
  • 幸存者偏差风险（未验证）：面板若剔除退市股，小盘篮子的最坏亏损（归零）会被漏掉 → 真实盈亏比/年化可能比我算的低。上线前请用含退市股的完整数据复核一次。
  • 风格切换是头号风险：低流动性占优在 2017–2020 失效。没有任何择时开关被验证有效，只能靠「胜率跌破 50% 减仓」被动应对。
  • 保守对照：若你不接受 −52% 回撤，退回「买入持有」版（strategy_final.py 口径），预期仅 +2.5%/年、回撤更小。
