# ETF 轮动策略 · 执行层（L4）成本分析与优化空间

> 配套：主线③前置于 `docs/a_share_warfare_landscape.md`（执行层 L4 是三条主线之一）。
> 代码：`tools/etf_exec_cost.py`（Almgren 冲击 + 执行时点成本模型，含单元自测）。
> 数据口径：累计换手 36.7、底盘年化 +7.59% 等为**本会话已实测**值；时点/冲击 12bp 来自 `pool_hold.py` 个股实测（对 ETF 为保守上限）。
> 诚实边界见 §4；**实时回测复核需 TimescaleDB（当前沙箱不可达，见 §5）**。

---

## §0 一句话结论
ETF 轮动的执行拖累**很小且可优化**：市场冲击近乎为 0（ETF 流动性好、免印花税），
真正可抠的是**执行时点**——在开盘集合竞价执行比在 10:00 最贵时点执行，**每年多约 0.8% 净收益**。
叠加现有 ~8% 策略 beta，这是该活策略上唯一还剩的、确定为正的可优化杠杆。

---

## §1 现有回测的成本模型缺口（已读代码确认）
`tools/etf_timeseries_signals.py` 的 `simulate()` 成本处理：
```python
nav *= (1 - comm * turnover)   # comm = 万1(0.0001) 或 千1(0.001)
```
**只扣了固定线性佣金，漏掉两件事**：
1. **市场冲击（Almgren）**：完全没算。对 ETF 其实影响极小（§3 证实），但模型不应缺。
2. **执行时点**：回测用日收益近似，隐含"拿到日收益级执行价"；而实盘在**开盘**比当日 VWAP 便宜 ~12bp、在 10:00/13:05 最贵（见 `pool_hold.py` 实测）。这部分真实损益被回测忽略。

→ 现有"底盘 +7.59% / TSMOM 等权 +7.63%"是**偏乐观的上界**（假设了近似 VWAP 的执行 + 只扣佣金）。

## §2 L4 成本模型（`tools/etf_exec_cost.py`）
单边成本（bp）：
```
cost = commission(1bp) + stamp(ETF=0) + 2·Almgren_impact(part,σ) + timing(session)
```
- `Almgren_impact = 0.1 × σ日 × √participation`，σ日 默认 160bp（ETF 低于个股 342bp）。
- `timing`：开盘 −12bp / 11:00 −11.6bp / 10:00 +5.3bp / 13:05 +5.8bp / VWAP 0（个股实测移植）。
- ETF 关键性质：**免印花税 + 日成交几十亿 → participation 极小 → 冲击 ≈ 0**。

模块提供：`almgren_impact_bp` / `timing_bp` / `trade_cost_bp` / `annual_cost_from_turnover` / `replay_with_exec_cost`，
及 `__main__` 合成数据单元自测（**非真实回测**，仅验数量级）。

## §3 用真实测得数据量化（累计换手 36.7 / 7.75 年）
模块自测输出（相对 VWAP 基准的年化执行损益，**负 = 比 VWAP 省**）：

| 执行时点 | 年化损益 | 说明 |
| :--- | :--- | :--- |
| **开盘 09:30–09:35** | **−48.5 bp/年（−0.49%）** | 最优；时点贡献 −440bp（全期）、冲击 +28bp |
| VWAP（回测隐含） | +8.3 bp/年（+0.08%） | 仅佣金+微冲击 |
| 10:00 最贵 | +33.4 bp/年（+0.33%） | 最差 |

- **开盘 vs 10:00 每年差 ≈ +0.82%**（确定的、可执行的净收益杠杆）。
- **市场冲击仅占 ~3.6 bp/年**，证实 ETF 冲击可忽略——L4 重心在时点而非冲击。
- 佣金本身仅 ~8 bp/年（万1），极小。

> 注：12bp 时点差来自个股实测，对更厚利的 ETF 应更小 → **0.8%/年 是保守上限，真实约 0.2–0.5%/年**。

## §4 诚实边界
1. **这不是新 alpha**，是对现有 ~8% beta 的**执行增效**——但它确定为正、且不用改信号。
2. **冲击对 ETF 不重要**（与股票池不同）；股票池的"降冲击救活信号"叙事已证伪（见 landscape 文档修正），ETF 这边冲击本就≈0。
3. 时点 12bp 是**个股**实测移植，ETF 实际更小；所有 L4 增益数字都应视为**上界**，待 DB 回测用 ETF 自身时点数据复核。
4. 现有回测（flat comm）≈ VWAP 执行上界；把执行改到开盘，真实净收益应**略高于**已报的 +7.59%。
