## 一、A股当下战法全景（按人群）

### 1. 游资 / 散户短线情绪战法（公众号/头条/淘股吧最热闹）
| 战法 | 做法 | 热度 |
| :--- | :--- | :--- |
| 龙头战法（打板/一进二/二板定龙） | 主线热点前3涨停、早盘封板、龙虎榜游资联动；按情绪周期（冰点→启动→发酵→高潮→退潮）进出 | 🔥🔥🔥 |
| 低吸龙头 / 龙回头 / 首阴反包 | 龙头回调至5/10/20日线低吸 | 🔥🔥🔥 |
| 情绪周期节点 | "冰点次日出手成功率>70%"，退潮期空仓 | 🔥🔥 |
| 连板梯队 / 涨停复盘 | 每日统计连板高度、炸板率 | 🔥🔥 |

→ **这正是本项目 `F1–F10` + 门控/时序信号覆盖的东西**（F4回踩MA20、F5首阴、F7龙回头全属此类）。SOP 最严口径下**全灭**（同 amount 档 IS/OOS 全负）。

### 2. 量化私募 / 机构（指增、中性、小微盘）
| 策略 | 2025 实测数据 | 本质 |
| :--- | :--- | :--- |
| 中证2000/1000/500 指增 | 超额单调：2000 **+23.27%** > 1000 +19.36% > 500 +13.81% > 300 +7.31% | **小市值风格暴露**，非纯选股 alpha |
| 市场中性（多空对冲） | 平均 +7.23%（受基差波动拖累） | 性价比受质疑 |
| 小微盘策略 | 2023 +47.57% → 2024.1 暴跌 **−34.9%** → 2025 续强 → 2026 上半年回撤 **−25%+** | "三低一高"逆向高抛低吸 + AI信号(占30%+)，容量小、易踩踏 |
| 红利低波 + 微盘"哑铃" | 2025 主流持仓结构（市值+红利双风格） | 风格β |
| 择时 / 多策略混合 / 衍生品保护 | 新兴方向 | 控波动 |

→ 印证本项目铁律：**机构超额主要来自市值结构 + 红利风格**，量价/基本面因子仅局部阶段性贡献。与"IC 随小盘程度单调正相关 = 风格因子非 alpha"完全一致。

### 3. ETF / 资产配置（圈内共识底仓，也是本项目唯一活口）
- 指数 ETF 极致估值（PB 历史百分位）：长线反转底仓。
- **ETF 网格交易**：中小资金、免印花税，震荡市收割波动（用户正在学网格，属此类）。
- **ETF 跨资产轮动**：本项目主策略（年化 ~7.6–8.5%、回撤可控）。

### 4. 可转债（散户/中小资金热门）
- 双低 / 低溢价轮动、折价套利：回撤可控、免印花税。逻辑与微盘轮动相似（高频反转）。

### 5. 红利 / 价值 / 反转（基本面量化）
- 红利量化轮动（高股息率+估值过滤）、自由现金轮回轮动（低PB+高FCF）：基于红利因子的均值回归。2025 红利为两大主流风格之一（中证红利低波100股息率 4.33% vs 10Y国债 1.69%）。

### 6. AI / 大模型选股（新兴，见 `docs/warfares_sources/2026-09-01_quantide_course_review.md`）
- 深度学习因子占比提升（中信保诚 >30%，当天执行优于隔日）；LLM 选股仍早期，多数课程停留在 FinBERT 情绪分类。

## 二、最关键的事实：热闹 ≠ 有边

1. **游资吹的龙头/打板/低吸/龙回头** = 我们用 SOP（三口径 + 滞后分档 + 成本敏感）**逐一证伪**的信号。其"能赚钱"幻觉来自：
   - 小市值风格暴露（2023–2025 微盘/小盘强，抱团自我强化）；
   - 情绪β（牛市/主升期普涨，随机抽也正）；
   - 幸存者偏差（只晒赚钱的，不提 2024 微盘 −34.9%、2025 −25% 的腰斩）。
2. **机构指增** 剥开是小市值 + 红利风格暴露，非纯 alpha；小微盘已多次崩盘（2024 −34.9%、2025 −25%），容量/流动性极脆。
3. **唯一在严格标准下活下来的 = ETF 轮动 / 资产配置**（beta，~8%，回撤可控）——与圈内"ETF底仓 + 网格/红利压舱"共识一致。

## 三、★ 后续主要研究方向（本项目主线）

用户真实目标 = **稳定赚钱、回撤可控**，非追市场 alpha。五轮测试已证伪股票横截面选股。后续研究**只走以下三条主线**，不再挖股票因子：

### 方向① 资产 / 配置层（最该深做，唯一证据上的"稳定小赚"）
- 深化 ETF 跨资产轮动：regime 切换、多资产扩展（不止现有 36 只）、战术/战略混合。
- 工具箱：ETF 网格（用户学习中）、红利低波压舱、指数 PB 百分位长线底仓。
- 定位：契合"稳定小赚"诉求，是主策略的自然延伸。

### 方向② 执行层 L4（最高未挖价值，最有信心）
- SOP 已定：**杠杆在 L4 降换手/降冲击，不在 L2 因子层**。
- 证据：F4 成本翻倍即归零（0.25%→+36.53bp、0.5%→+11.53bp、1%→−38.47bp）。
- 动作：用 `bars_5m`（2026+ 可用）做 scheduling / TWAP / 批量降冲击，原"死掉"的信号可能复活。
- 诚实标注：5m 仅 2026+ 有，partially feasible。

### 方向③ 风险 / 组合层（补 `research_sop.md` §7 短板，超 3–4 年研究员突破口）
- 当前只会等权 / 逆波动。做真组合构建 + 风险模型（控制暴露、降相关性）。
- 这是"超越机构3~4年研究员"的实处，也是项目最薄的一环。

### 明确停止
- **不再挖股票横截面因子**（F1–F10 + 10横截面 + 7门控/时序已证伪）。证据明确：成本结构下无 alpha。

## 四、期望管理（必须说清）
- 用户曾提"月 10%" → 本项目**任何**回测都未出现（复利≈214%/年，不现实）。
- 可达目标 = **ETF beta ~8% + 执行/风险优化带来的稳健性提升**。能稳定拿这个、回撤压住，已跑赢多数散户，契合"只要能赚"底线。
- 任何新方向仍须走 `research_sop.md` 十步流水线 + 三口径 + 成本敏感，任一关不过不出结论。
