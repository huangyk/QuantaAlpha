## 二、★ 首推：`etf-adaptive-rotation-qmt`（v0.5.2，MIT）

> 面向 QMT/迅投的 T+0 ETF 自适应轮动。18 个 Python 模块 / 8 个 CLI 子命令 / **134 项自动化测试** / 12 只跨资产 ETF。
> https://github.com/guoyaohua/etf-adaptive-rotation-qmt

### 它做对了什么（这正是本站缺的东西）
不是"再挖一个更强信号"，而是**把组合构建/风险/执行/审计做扎实**——与本项目既得结论
（"真杠杆在 L4 执行层，不在 L2 挖因子"）完全一致。

### 核心公式（可直接抄）
**① 多周期动量（跳过最近5日，避开短周期反转噪音）**
```
M_i = 0.20·R20_i(-5) + 0.30·R60_i(-5) + 0.50·R120_i(-5)
```
**② 风险调整横截面分数（对波动非线性惩罚）**
```
Score_i = M_i / max(σ40_i, 0.10)^0.75
```
**③ 逆波动率初始权重**
```
w_i = (1/σ_i) / Σ_j (1/σ_j)
```
**④ 波动率上限 10%**：预估年化波动 >10% 时**只向下缩放**，低波动时**不杠杆补足**（这点很关键，避免了目标波动策略常见的隐性加杠杆）。
约束：**单资产 ≤40%、总敞口 ≤90%**。

**⑤ 四周错峰（sleeve）**：资金分 A/B/C/D 四份，**每周只替换一份旧信号**，每份 25%。
→ 消除"单一调仓日运气"对整仓的支配，把一次性择时风险摊到四周。

**⑥ 货币 ETF 现金管理**：未用完的风险预算由 `511880.SH` 承接，**最多 30%**，不参与主排名，年末分红黑窗强制退出。

**⑦ 风险内核**：ATR 初始止损/跟踪止损、组合级回撤、单日亏损、冷却与退出锁存。
**⑧ 执行/审计**：整手订单、免交易带（no-trade band）、先卖后买、稳定计划ID、重复提交防护；代码/配置/行情/会话 **SHA-256 指纹**；**fail-closed**（任何关键输入异常就拒绝而非猜测）。

### 它自己公开的数字（诚实得罕见）
区间 2015-01-05 → 2026-07-10，100 万初始，**已计佣金和滑点**：

| 成本场景 | CAGR | 累计 | 最大回撤 | Sharpe | Calmar |
|---|---|---|---|---|---|
| 1× 基础 | **5.83%** | 91.96% | **6.46%** | **1.004** | 0.902 |
| 2× 压力 | 4.92% | 73.77% | 6.65% | 0.854 | 0.740 |
| 3× 压力 | 3.97% | 56.56% | 6.83% | 0.695 | 0.581 |

- **10/10** 个滚动三年窗口 CAGR 为正，**最差窗口 +2.36%**
- **2,098** 净值日、**1,182** 笔成交做**前缀不变性**检验 → 未来数据没重写既有结果
- 行情 union 与 XSHG 日历 **2798/2798** 会话一致
- 自称边界：存在 ETF 池**幸存者偏差**；日线 OHLC 无法还原盘中路径/折溢价/停牌/盘口冲击

> 它收益更低但**回撤只有我们的 1/3.4、夏普更高** —— **差异几乎全在组合层与风控层，不在信号层**。

## 三、值得照搬的"层"（按优先级）

对照本项目 `tools/backtest_qixing.py` 与 `pool_hold` 现状，建议按此顺序加：

1. **波动率上限 + 逆波动率权重**（P0）——直接把回撤从 −22% 量级压下去，无需新因子。
2. **四周错峰 sleeve**（P0）——本项目已证明"降换手就是涨收益"，错峰是降换手的工程化做法，
   且与我们已经得到的"月频优于日频"结论同向。
3. **相关性过滤 / 风险组去重**（P1）——本站 34 只 ETF 里有大量同质标的
   （588000/588080、513130/513180、510500/512500 高度重合），去重能避免"以为分散、实则重仓同一风险"。
4. **ATR 初始/跟踪止损 + 组合回撤降级**（P1）——正好补上 5 步框架的第⑤步（止损），目前框架里最弱的一环。
5. **货币 ETF 承接闲置资金**（P2）——511880 我们库里已有干净数据，可直接用。
6. **前缀不变性 + 参数/数据 SHA-256 指纹**（P2）——把"防未来数据"变成**可自动回归的测试**，
   比人肉检查可靠得多（本项目今天才刚被 by .iloc 索引错位坑过一次）。

## 四、避坑：怎么识别"吹牛策略"

调研时看到两类典型话术，都别信：

- **"聚宽年化30%+ ETF轮动"** —— 本站已用干净 QMT 真实数据、T+1 对齐、同口径基准复现：
  LB 15~35 全扫描年化仅 **4.6%~10.1%**，且 **LB=25 无孤立优势**（噪声带），是过拟合产物。
  （对应 `docs/qixing_etf_verdict.md`）
- **"ML 三模型投票，年化118%、回撤6%、胜率88%、夏普7.24"** —— 一眼假的三个信号：
  ① Sharpe >7 且回撤 <7% 在真实市场几乎不存在；② 只用 **2 年**样本 + 50+ 特征 + 三个 GBDT = 典型过拟合配置；
  ③ 回测区间 2024-04~2026-04 正好覆盖单一上涨窗口。**要求它给滚动窗口与成本压力测试，给不出就是不能信。**

**通用判据（以后看任何策略先用这三条）**：
1. 有没有**滚动窗口**全部为正？给不出最差窗口的就是在挑样本。
2. 有没有**2×/3× 成本压力**？不含冲击成本的 P&L 一律作废（本站已有教训：成本吃掉 −36.98%/年）。
3. 有没有**防未来数据**的验证（前缀不变性/ `avoid_future_data`）？这是本站踩得最多次的坑。
