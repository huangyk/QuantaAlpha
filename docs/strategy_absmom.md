# 战法：跨资产趋势跟随（200日SMA + 逆波动率）

> **要直接上手用，照 `docs/ops_checklist.md` 做即可**（冻结配置 + 每月3步操作 + 上线前验证）。
> 唯一经 QMT 实盘数据验证、可落地的指数/ETF 层策略。其余「关口支撑 / 抢反弹 / 顺趋势抄跌 / 单指数MA门控」均已证伪，详见 `docs/index_technical_verdict_report.html`；股票路线亦已证伪（`docs/stock_verdict.md`）。
> 本文件为可部署规格：QMT 版 `quantaalpha/strategy/absmom_qmt.py`、Ptrade 版 `quantaalpha/strategy/absmom_ptrade.py` 逻辑完全一致（均含 `EXPOSURE` 暴露比例参数，1.0=满仓 / 0.6=低回撤档）。

## 1. 一句话
对池里每只 ETF **独立**判趋势：收盘价站在自身 200 日移动平均线之上才持有，否则该份额转现金；持有子集内按**逆波动率**分配权重。每月调仓一次。

## 2. 参数
| 参数 | 值 | 说明 |
|---|---|---|
| 标的范围 | 跨资产 ETF 池（38 只：股/债/货基/商品/黄金/境外） | 见 `POOL` 列表；QMT 与 Ptrade 两平台标的需一致 |
| 趋势信号 | `close > SMA(200)` | 用前一日收盘判，次月首个交易日生效（无前视） |
| 调仓频率 | 月频 | 月末判信号，次月调仓；平均年调仓 ~12 次 |
| 权重 | 逆波动率 | `w_i = 1/σ_i`，`σ_i`=60 日年化波动率（下限 0.05 防极值），持有子集内归一 |
| 佣金 | 万1（0.01%） | ETF 无印花税；月频低换手，成本可忽略 |
| 现金处理 | 跌穿均线的份额清为现金，不生息 | 等待重新站上 200 日线再回补 |

## 3. 规则（伪代码）
```
每月末：
  for 每只 ETF:
      sma200 = 近200日收盘均值
      if close > sma200: 标记为持有
  held = 所有标记持有的 ETF
  if held 为空: 全部现金; 结束
  for x in held:
      vol[x] = 近60日收益标准差 * sqrt(252)
      inv[x] = 1 / max(vol[x], 0.05)
  tot = sum(inv)
  for x in held: target_weight[x] = inv[x] / tot
  调仓：持仓子集按 target_weight 配置，其余归零（现金）
```

## 4. 回测结论（QMT 数据回填，38 只，2019-01-01 ~ 2026-09-30）
| 策略 | 年化 | Sharpe | 最大回撤 | 在市 |
|---|---|---|---|---|
| 纯等权持有（基线） | 10.9% | 0.71 | −23.0% | 100% |
| **200日SMA + 逆波动率（本战法）** | **10.0%** | **1.03** | **−9.4%** | 89% |
| 200日SMA + 等权 | 12.6% | 0.85 | −17.4% | 89% |

- **regime 分段**（80 个月）：牛市 40 月 策略 +16.0% vs 基准 +23.2%（落后，保护的代价）；震荡 31 月 +5.5% vs −2.1%（超额 +0.62%，胜率 71%）；熊市 9 月 +6.4% vs −9.6%（超额 +1.36%，胜率 67%）。
- **防过拟合三重测试全过**：walk-forward 隔离测试 Sharpe 1.04 vs 等权基线 0.77（双配置跑赢）；SMA 窗口 60~250 参数成簇无尖峰；佣金万1→千1 均跑赢基线。
- **当前信号（2026-10-08）**：38 只中 11 只持有，约 60% 仓位压在国债/城投债/货基（防守姿态），真实权益/商品敞口约 40%。

## 5. 定位（对应用户目标）
用户目标：**稳定赚钱、回撤可控，非发财/非追 alpha**；月 10% 为高标杆、底线「只要能赚」。
本战法 = **已验证的「赚钱底盘」**：年化 ~10%、回撤 −9.4%、熊市不亏反赚。月化 10%（≈年 214%）任何回测未现，属不现实标杆；更高月收益需另找已验证高收益边缘，不得据此放松验证。

## 6. 两平台部署
- **QMT**：`absmom_qmt.py` 用 `xtquant.xtdata` 取数，`init()` 订阅、`handlebar()` 月末调仓；QMT 客户端「策略回测」加载即可回测，实盘需先 `connect()`。
- **Ptrade**：`absmom_ptrade.py` 用 Ptrade 标准 API（`initialize`/`handle_data`/`order_target_value`/`attribute_history`），直接丢进 Ptrade 回测器；逻辑与 QMT 版逐行一致，同一份数据下回测结果相同。
- **每月流程**：跑 `python -m tools.index_lab signal` 刷新信号 → 跑 `python -m tools.index_lab.make_order_list 80000` 出下单清单（或任意资金额）→ 在两平台执行。

## 7. 风险与注意
- 样本 ~7.7 年，熊市段 9 个月，方向明确但须持续跟踪。
- 当前 60% 现金类，近端预期低于年化 10%，属防守；趋势转好会自动加回权益。
- 数据须来自 QMT（本项目铁律，禁止默认 akshare 替代）；Ptrade 端用其自有数据，结论以 QMT 回填为基准对照。

## 8. 高收益 sleeve 探索结论（2026-10-11）
脚本 `tools/index_lab/method_higher.py`，复跑 `python -m tools.index_lab higher`。
在底盘之上试了两条提收益的假设，均用「同池等权基线 + walk-forward 隔离 + 参数/成本敏感」严格检验：

| 配置 | 年化 | Sharpe | 回撤 | 判定 |
|---|---|---|---|---|
| 底盘 全池 sma200/逆波动（现役） | 10.0% | 1.03 | −9.4% | 风险调整最优 |
| H1 高beta池(剔4只纯固收) sma200/等权 | 13.4% | 0.79 | −20.7% | OOS 通过，回撤翻倍 |
| H1 高beta池 sma200/逆波动 | 12.0% | 0.81 | −19.2% | OOS 通过（测试窗 15.5%/1.11） |
| H2 高beta topk5/逆波动 | 19.9% | 1.02 | −19.2% | **样本内诱人，OOS 证伪** |
| H2 高beta topk3/逆波动 | 17.3% | 0.72 | −41.5% | **OOS 亏钱（−1.7%），不可用** |

- **H2（TopK 动量集中）证伪**：训练窗选出 topk5（Sharpe 1.14），隔离测试窗仅 0.43（基线 0.74）；预设 topk3 年化 −1.7%、Sharpe −0.08。19.9% 属过拟合。
- **H1（剔除纯固收/货币，只跑股+商品+黄金+境外）通过**：训练窗选等权（0.86）→ 隔离测试窗 选参 0.84、预设逆波动 1.11/年化 15.5%/回撤 −14.1%，均跑赢同池基线 0.74；成本万1→千1 仍跑赢（0.81→0.78 vs 0.69）。
- **代价**：H1 回撤约翻倍（−19~−20% vs 底盘 −9.4%），全周期 Sharpe 低于底盘。
- **结论**：要更高**绝对收益**可用 H1（约 13~15%/年），须接受回撤翻倍；底盘仍是**风险调整/低回撤**首选。8万本金下 H1 最坏浮亏约 1.5万，底盘约 7.5千。两者均未触及月 10%。
- **待办（已解）**：底盘 + H1 混合比例经 `tools/index_lab/method_higher.py` 前沿扫描（五档 + walk-forward OOS + 逐年滚动 OOS + 杠杆/vol-target/Bootstrap 多项检验），结论：**25% H1 为甜点**（年化 ~10.5%/Sharpe 0.85/回撤 −11.9%，部署干净、保留债券压舱）；详见 `docs/blend_frontier.html`。

## 9. 低回撤档（60% 恒定暴露）+ ML/DL 择时结论（2026-10-12）
### 9.1 低回撤档（推荐给「回撤可控/能睡着」诉求）
把**已验证的底盘策略按 60% 暴露**持有、其余 40% 现金，是一个无需模型、确定性的降回撤方案：
| 方案 | 年化 | Sharpe | 最大回撤 |
|---|---|---|---|
| 底盘满仓（现役） | 10.0% | 1.03 | −9.4% |
| **底盘 60% 暴露** | **5.5%** | **1.03** | **−4.8%** |
| 底盘 50% 暴露 | 4.6% | 1.03 | −4.0% |

回撤直接减半（−9.4% → −4.8%），Sharpe 不变（因降杠杆线性缩放），代价是年化降到 ~5.5%。**对"只要能赚、回撤别太大"的用户，这是最干净的低回撤档**——比任何 ML 择时都稳（见 9.2）。

### 9.2 ML/DL 择时叠加层验证（已证伪「无真 alpha」）
用户要求加入机器学习/深度学习。已建 `tools/index_lab/method_ml.py`：在底盘上叠加 **LightGBM + XGBoost + PyTorch MLP** 月频择时（expanding-walk-forward，严格无前视），并做硬择时（预测涨才全仓）/软加权（暴露=上涨概率）/**恒定比例空基准**三联对比 + 逐年滚动 OOS。
- **硬择时**：三模型均跑输朴素持有（LightGBM 0.51、XGBoost 0.71、MLP 1.03 但=100%月份判持有=没择时）。
- **软加权**：MLP 5.1%/Sharpe 0.99/−4.9%（平均暴露 58%），回撤降低但 Sharpe 仍低于满仓。
- **空基准证伪（决定性）**：恒定 60% 持有 = 5.5%/Sharpe **1.03**/−4.8%，与最优软加权（MLP 5.1%/Sharpe **0.99**）几乎重合，且 **ML 的 Sharpe 反而略低于**朴素恒定 60%——证明 ML 软加权只是"把暴露恒定降到 ~60% 的降杠杆"，**没有任何择时预测本事**。
- **逐年 OOS（2022–2026）**：3/5 年恒定 60% 的 Sharpe ≥ 最优软加权，软叠加层无稳定超越。
- 增强特征（多期限宽度 + 风险偏好 + 期限利差 + 黄金 + 横截面离散度）重测，**结论不变**。
- **裁定**：样本仅 ~90 个月度点（44 测试月），ML/DL 择时层**不创造 alpha**，与项目既有「ML 因子证伪」一致；要产生价值需更大样本或更具预测力的特征。已验证的古典趋势跟随仍是本池最稳策略。**故落地时直接用 9.1 的 60% 恒定暴露档满足低回撤诉求，不必上 ML。**
- 详细报告：`docs/ml_timing_report.html`（硬/软/空基准三表 + 逐年 OOS + 裁定）。
- 铁律备注：本环境 `sklearn.LogisticRegression.fit()` 静默 segfault（二进制兼容 bug），故 ML 用 LightGBM/XGBoost、DL 用 PyTorch MLP。
