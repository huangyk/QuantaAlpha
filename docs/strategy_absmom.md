# 战法：跨资产趋势跟随（200日SMA + 逆波动率）

> 唯一经 QMT 实盘数据验证、可落地的指数/ETF 层策略。其余「关口支撑 / 抢反弹 / 顺趋势抄跌 / 单指数MA门控」均已证伪，详见 `docs/index_technical_verdict_report.html`。
> 本文件为可部署规格：QMT 版 `quantaalpha/strategy/absmom_qmt.py`、Ptrade 版 `quantaalpha/strategy/absmom_ptrade.py` 逻辑完全一致。

## 1. 一句话
对池里每只 ETF **独立**判趋势：收盘价站在自身 200 日移动平均线之上才持有，否则该份额转现金；持有子集内按**逆波动率**分配权重。每月调仓一次。

## 2. 参数
| 参数 | 值 | 说明 |
|---|---|---|
| 标的范围 | 跨资产 ETF 池（38 只：股/债/货基/商品/黄金/境外） | 见 `POOL` 列表；QMT 与 Ptrade 两平台标的需一致 |
| 趋势信号 | `close > SMA(200)` | 用前一日收盘判，次月首个交易日生效（无前视） |
| 调仓频率 | 月频 | 月末判信号，次月调仓；平均年调仓 ~12 次 |
| 权重 | 逆波动率 | `w_i = 1/σ_i`，`σ_i`=60 日年化波动率（下限 0.05 防极值），持有子集内归一 |
| 佣金 | 万1（0.01%） | ETF 无印花税；月频低换手，成本可忽略 |
| 现金处理 | 跌穿均线的份额清为现金，不生息 | 等待重新站上 200 日线再回补 |

## 3. 规则（伪代码）
```
每月末：
  for 每只 ETF:
      sma200 = 近200日收盘均值
      if close > sma200: 标记为持有
  held = 所有标记持有的 ETF
  if held 为空: 全部现金; 结束
  for x in held:
      vol[x] = 近60日收益标准差 * sqrt(252)
      inv[x] = 1 / max(vol[x], 0.05)
  tot = sum(inv)
  for x in held: target_weight[x] = inv[x] / tot
  调仓：持仓子集按 target_weight 配置，其余归零（现金）
```

## 4. 回测结论（QMT 数据回填，38 只，2019-01-01 ~ 2026-09-30）
| 策略 | 年化 | Sharpe | 最大回撤 | 在市 |
|---|---|---|---|---|
| 纯等权持有（基线） | 10.9% | 0.71 | −23.0% | 100% |
| **200日SMA + 逆波动率（本战法）** | **10.0%** | **1.03** | **−9.4%** | 89% |
| 200日SMA + 等权 | 12.6% | 0.85 | −17.4% | 89% |

- **regime 分段**（80 个月）：牛市 40 月 策略 +16.0% vs 基准 +23.2%（落后，保护的代价）；震荡 31 月 +5.5% vs −2.1%（超额 +0.62%，胜率 71%）；熊市 9 月 +6.4% vs −9.6%（超额 +1.36%，胜率 67%）。
- **防过拟合三重测试全过**：walk-forward 隔离测试 Sharpe 1.04 vs 等权基线 0.77（双配置跑赢）；SMA 窗口 60~250 参数成簇无尖峰；佣金万1→千1 均跑赢基线。
- **当前信号（2026-10-08）**：38 只中 11 只持有，约 60% 仓位压在国债/城投债/货基（防守姿态），真实权益/商品敞口约 40%。

## 5. 定位（对应用户目标）
用户目标：**稳定赚钱、回撤可控，非发财/非追 alpha**；月 10% 为高标杆、底线「只要能赚」。
本战法 = **已验证的「赚钱底盘」**：年化 ~10%、回撤 −9.4%、熊市不亏反赚。月化 10%（≈年 214%）任何回测未现，属不现实标杆；更高月收益需另找已验证高收益边缘，不得据此放松验证。

## 6. 两平台部署
- **QMT**：`absmom_qmt.py` 用 `xtquant.xtdata` 取数，`init()` 订阅、`handlebar()` 月末调仓；QMT 客户端「策略回测」加载即可回测，实盘需先 `connect()`。
- **Ptrade**：`absmom_ptrade.py` 用 Ptrade 标准 API（`initialize`/`handle_data`/`order_target_value`/`attribute_history`），直接丢进 Ptrade 回测器；逻辑与 QMT 版逐行一致，同一份数据下回测结果相同。
- **每月流程**：跑 `python -m tools.index_lab signal` 刷新信号 → 跑 `python -m tools.index_lab.make_order_list 80000` 出下单清单（或任意资金额）→ 在两平台执行。

## 7. 风险与注意
- 样本 ~7.7 年，熊市段 9 个月，方向明确但须持续跟踪。
- 当前 60% 现金类，近端预期低于年化 10%，属防守；趋势转好会自动加回权益。
- 数据须来自 QMT（本项目铁律，禁止默认 akshare 替代）；Ptrade 端用其自有数据，结论以 QMT 回填为基准对照。
