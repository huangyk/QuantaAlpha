# 操作清单：从研究到实盘（ETF 跨资产趋势跟随）

> 冻结配置：跨资产 ETF 趋势跟随 = 每只 ETF 独立判 `close > 200日SMA`，站上才持有，组内按**逆波动率**分配，**月频调仓**，佣金万1。数据源：QMT（禁止用 akshare 替代）。
> 本清单照做即可，无需再研究。股票路线已证伪（见 `docs/stock_verdict.md`），不要在股票上再投入。

## 一、选哪一档（先定这个）
| 档位 | 曝光 | 年化 | 回撤 | 适合 |
|---|---|---|---|---|
| **主用档（推荐先用这个）** | 100% | ~10% | −9.4% | 想完整跟策略、能接受 1 成回撤 |
| **低回撤档** | 60% | ~5.5% | −4.8% | 更看重"回撤小、能睡着" |

切换方式：QMT/Ptrade 脚本里的 `EXPOSURE = 1.0` 改成 `0.6` 即可（其余逻辑不变）。

## 二、每月操作（交易日做，3 步）
**第 1 步 · 刷新信号**（研究端，本机 quantaalpha 环境）
```bash
python -m tools.index_lab signal
```
输出当前每只 ETF 站上/跌破 200 日线，写 `data/results/current_holdings.csv`。

**第 2 步 · 生成下单清单**（研究端）
```bash
# 主用档（100%）
python -m tools.index_lab.make_order_list 80000 0 1.0
# 低回撤档（60%）
python -m tools.index_lab.make_order_list 80000 0 0.6
```
> 参数：`资金 blend exposure`（blend 是 H1 卫星比例，主用/低回撤档都填 0）。
> 输出 `data/results/order_list_<资金>_b0_e<暴露>.csv`：代码/名称/动作/现价/占总%/目标元/股数/金额。

**第 3 步 · 执行**：在 QMT/Ptrade 按清单下单（研究端数据截至 2026-09-30，**实盘前用 QMT 实时数据复核现价**）。

> 注意：研究端清单用的是数据库价格，实盘请用 QMT 当日价格。信号逻辑两边一致，价格以 QMT 为准。

## 三、上线前必须做的两步验证
1. **QMT 回测复核**：把 `quantaalpha/strategy/absmom_qmt.py` 加载进 QMT「策略回测」，确认年化/回撤与研究端接近（研究端：年化~10%、回撤−9.4%）。差异大就查数据口径，**不要直接上实盘**。
2. **模拟盘小额试跑**：先上 1–2 万跑 1–2 个调仓周期，核对"清单股数 vs 实际成交"，确认一致、无异常滑点后再加仓。

## 四、日常维护
- **频率**：月频（每月末判信号、次月首个交易日调仓），全年约 12 次——符合"少交易"。
- **何时该动手**：只有月末调仓日。平时不动。
- **何时该担心**：连续 2–3 个月在市比例骤降、持仓大幅变动 → 检查是否数据源出问题。
- **当前信号（2026-10-08）**：38 只中 11 只站上均线，其中约 60% 权重压在国债/城投债/货币 ETF——**防守姿态**，属正常，趋势转好会自动加回权益。

## 五、常见坑（都是本项目踩过的）
- ❌ 改用 akshare 补数据 → 数据不准。QMT 是唯一权威源。
- ❌ 月频策略做成日频 → 换手爆炸、成本吃掉收益。
- ❌ 用研究端价格直接下单 → 必须用 QMT 实时价。
- ❌ 在股票池上重试 → 已证伪，股票做不出低回撤（见 stock_verdict）。

- 策略说明（含参数/伪代码/回测）：`docs/strategy_absmom.md`。
