# 因子成绩表（2026-10-09，基于磁盘真实评估）

> 用户疑问："这么多因子我都不知道好用不"。
> 本文把所有挖出来的因子按**真实全 A 面板评估结果**逐一定性，结论是：
> **作为"能提取超额收益(alpha)的信号"，基本都不好用；少数真有统计显著性的，是风格/流动性因子，只能当风险过滤器，不能当选股器。**

---

## 0. 一句话总裁定律

**在本项目 A 股全 A 设置（真实成本、正确 T+1 对齐、同池等权基准）下：**

- 横截面选股 alpha **全员证伪**（飞龙 / 战法2 / 沪深300闸门 / 5min低波动族 / 短期反转+量能退潮）。
- 唯一存活的是 **beta（低换手池等权持有）**，不是任何因子。
- 因子天花板：毛 alpha ≈ 9%/年 < 执行成本 12%+/年 → 净值恒为负。
- **正 IC ≠ 可提取 alpha**：分组不单调时，持 Top-K 拿不到中间组的收益。

## 1. 19 个日线因子（eval_1d.csv，盘上真实评估）

rdagent 在日线面板挖出的 19 个因子（C1–C9 + F1–F9），重新在全部 A 股上面板评估：

| 指标 | 数值 | 含义 |
|---|---|---|
| RankIC_all 为正的数量 | **0 / 19** | 全部为负（−0.0018 ~ −0.0367） |
| topk_sharpe 为正的数量 | **0 / 19** | 全部为负（−0.04 ~ −2.24） |
| 最强(最不差) | F4（RankIC −0.0018，夏普 −1.21） | 仍为负 |

**结论：这 19 个因子在真实全 A 面板上无一成立。** 记忆里"19 个强因子"的说法，来自 5min CoSTEER 在**窄样本**上 `|t|≥2 且三段同号` 的门槛——那个门槛是**样本内/窄样本产物**，放到全 A 面板即崩。

> ⚠️ 这就是"挖出来 IC 很高、实盘不赚钱"的典型陷阱：rdagent 的 proposer 在训练段把因子调得好看，但全 A 面板（含次新、小盘、停牌）一跑就现原形。

## 3. 传统因子库（validated_factors_ensemble.json，15 个传统 + 19 个 mined）

### 3.1 传统因子——统计显著，但是"风格因子"不是"个股 alpha"

| 因子 | 表达式 | t 值 | 方向 | 真实含义 |
|---|---|---|---|---|
| F11–F14 RVOL (收益波动) | `TS_STD($return, N)` | **−6.6 ~ −7.2** | 负 | 低波动溢价（真实且强） |
| F15–F18 GARKLINE / RANGERATIO | `TS_MEAN(Log($high/$low), N)` 等 | **−6.8 ~ −7.2** | 负 | 低振幅溢价（真实且强） |
| F24/F25 AMIHUD | `ABS($return)/($volume+1)` | −4.0 | 负 | 低流动性溢价 |
| F26/F27 EFF_CO | `ABS($close-$open)/($high-$low)` | −4.1 ~ −4.4 | 负 | 实体效率（低波动） |
| F9/F10 DIRCONS | `TS_SUM(SIGN($return), N)` | +2.5 / +2.8 | 弱正 | 方向一致性（弱） |
| F20 VOLRATIO | `$volume/TS_MEAN($volume,48)` | +2.3 | 弱正 | 放量（弱） |

**关键判读**：RVOL / GARKLINE / RANGERATIO 这族 **t 值 −7 左右，是全盘最强的统计信号**——但它们测的是"低波动/低振幅股票未来涨"，这是已被学术证实的**低波动异象（风格因子）**，不是某只股票独有的 alpha。IC 与"小盘程度"单调正相关（见项目裁定），加流动性约束后消失，过换手成本后归零。

> ⚠️ **勘误（2026-10-09）**：此"风格因子"定性已被真中性化检验推翻——见第 8 节。用 `bars_1d` 流通市值代理做横截面中性化后，低波动 IC 不降反升至 +0.0332/t=6.17，说明它独立于市值。原"加流动性约束后消失"仅对 rdagent 那批短期反转因子成立，低波动异象是经典有效异象，不适用。

## 6. 给你的直白建议（下一步）

1. **别再迷信"因子数量"**。19 个、10 个，盘上数字再好看，全 A 真实评估都是负 IC。因子多 ≠ 有用。
2. **把真信号降级为"过滤器"**：用低波动/低振幅因子做**排雷**（剔除高波动股），而不是当 alpha 打分。这能实打实降回撤，不指望它赚超额。
3. **实盘能落地的只有两条路**：
   - **路 A（保守）**：低换手跨资产等权持有（ETF 轮动结论：34 只等权 +9.3%/夏普 0.65，回撤 −22%）。接受高回撤换高夏普。
   - **路 B（控回撤）**：等权持有 + 分级回撤守护（6~8% 阈值）→ 回撤压到 −6~−8%，代价年化掉到 ~3%。
4. **想再挖因子，先补数据**：行业分类 + 市值 + 涨跌停/ST 标记目前全缺。中性化后 alpha 才可能被释放——在现有池上继续挖日线因子，天花板已被"毛 alpha 8.94% < 成本 12.46%"封死，挖了也白挖。

## 8. 低波动异象真中性化检验（2026-10-09，颠覆第 3.1 节旧裁定）

### 8.1 为什么做
第 3.1 节把 RVOL/GARKLINE/RANGERATIO 这族 t≈−7 的信号判为"低波动风格因子，不是个股 alpha，中性化后归零"。但这是基于"IC 与小盘程度单调正相关"的间接推断，没做过真中性化。本次用全 A 真实面板直接检验。

### 8.2 方法（严格按验证铁律）
- 数据：TimescaleDB `bars_1d`（QMT datadir 回填，不碰 akshare），全 A 非 ETF，2014-01-02~2026-09-30，1084 万行 / 5355 只
- 信号：20 日已实现波动率取负排名（低波动=高信号）
- 目标：T+1 开盘收益（open_{t+1}/open_t − 1），无前视
- 市值代理：float_mcap = close × float_shares（表自带 float_shares）
- 过滤：剔次新(<250日)、剔涨停买不进(open/昨收≥1.098)、剔跌停、剔 ST
- 中性化：横截面用市值排名对信号回归取残差（size-neutral）
- 成本：万1 双边 + 按市值分层冲击（小盘30bp/中盘12bp/大盘5bp 单边）
- 脚本：tools/factor_neutral_test.py

### 8.3 结果（IC 层，旧脚本与本次一致）
| 指标 | 数值 |
|---|---|
| 有效样本 | 4,589,246 条（剔除次新/涨跌停/ST/缺失后） |
| 原始 IC | +0.0324 (t=+5.55) |
| **市值中性化 IC** | **+0.0332 (t=+6.17)** |
| **行业+市值中性 IC（本次补）** | **+0.0312 (t=+7.35)** |

> ⚠️ **重大勘误（2026-10-12，见 docs/lowvol_true_neutral_verdict.md）**：旧脚本 `factor_neutral_test.py` 的"多空组合 +27.3%"是 **decile 方向标错**——`pd.qcut(sig_neu,10)` 中 decile 0=最高波动、decile 9=最低波动，旧脚本 `long=dec0/short=dec9` 实际是**做多高波动/做空低波动**（小盘投机溢价），却误标为"低波动多/高波动空"。**正确方向的多空并不赚钱**：

| 组合（方向正确, 本次 `factor_lowvol_true_neutral.py`） | 年化 | 夏普 | 回撤 |
|---|---|---|---|
| 极端多空（最低波动多/最高波动空）日频 | **−29.7%** | −1.43 | −88.5% |
| 宽口多空（低波动半多/高波动半空）日频 | **−26.9%** | −2.20 | −83.2% |
| 排名加权多空（rank IC 直接转零成本组合） | **−8.6%** | −4.34 | −38.2% |
| long-only 大盘低波动（前300市值内低波动半） | −13.9% | −2.67 | −4.0% |
| long-only 流动盘极端（最低波动） | −34.0% | −1.93 | −89.0% |

### 8.4 解读（关键，修订版）
1. **低波动是真实横截面 rank 信号，不是风格因子**：行业+市值中性后 IC 不降反升（t 5.55→7.35），独立于行业/市值/流动性。这层旧裁定（真信号）成立。
2. **但 rank IC 为正 ≠ 均值收益为正（厚尾背离）**：A 股高波动股=小盘投机票，有极厚正收益右尾。rank 相关压缩尾部，故低波动在**中位数**占优（IC>0）；但**均值**被高波动股右尾主导，故所有用原始收益的多空/单多都为负。探针(`tools/_probe_rankweight.py`)：每日 Spearman(sig,rank_ret)=+0.0392，但 Pearson(sig,原始ret)=−0.0158 —— 信号只在序数层面有效，均值层面被吞噬。
3. **A 股是美股低波动异象的"镜像"**：Ang(2006) 美股低波动原始收益也更高；A 股反之，高波动小盘原始收益更高，故正确方向多空亏钱。旧 +27.3% 实为小盘溢价，不是低波动异象。

### 8.5 "好用不"的最终判词（二次修正版）
| 维度 | 结论 |
|---|---|
| 作为横截面 rank 信号 | **真实**（行业+市值中性 IC t=+7.35，全 A 稳健） |
| 多空配对（正确方向） | **亏钱**（−29.7% 极端 / −8.6% 排名加权） |
| 单边长持低波动股 | **亏钱**（−13.9%~−34%） |
| 实盘可落地的用法 | **仅防御降回撤**：大盘低波动回撤仅 −4.0%（对比极端 −89%），可作仓位风控偏向，不是 alpha 来源 |

### 8.6 谨慎声明
- IC 层结论强且可信（基于连续 rank 相关，无前视）；组合层全为负，方向无误（本次用显式 `rank(pct=True)` 长/短腿，非 `pd.qcut` 易错方向）。
- 排名加权多空 −8.6% 证明即便把 rank IC 直接转成零成本组合，均值收益仍为负——低波动信号**无经济 payoff**，仅序数层面成立。
- 低波动信号从"真 alpha 但须多空(做空受限难变现)" 降级为 "真实 rank 信号, 但均值收益不可变现, 仅作防御过滤器"。与 §0 总裁定律一致：所有横截面选股 alpha(含低波动)在 A 股均不可变现。
