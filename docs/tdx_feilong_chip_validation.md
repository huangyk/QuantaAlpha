## 1. 第 5 点：筹码分布怎么算（COST/WINNER 还原）

通达信 `COST(N)` / `WINNER(P)` 本质是**逐日换手加权持仓成本**的分布。本库 `bars_1d` 只有 OHLCV
（QMT datadir 回填），本没有筹码数据——但 `float_shares` + `turnover_rate` 齐全（4,360 只股票有），
足够还原。采用 TDX 官方"成本分布"**衰减模型**：

```
对每一交易日 t（按时间顺序）:
  均价 avg = (H + L + 2*C)/4              # TDX 给收盘更高权重
  换手率 turn = turnover_rate（有则用）；否则 volume×100 / float_shares
  当日成交按三角形分布铺在 [L, H]，峰值在 avg（面积=1）
  衰减更新: D_t = D_{t-1}*(1−turn) + turn×当日三角形
  （每天有 turn 比例老筹码"移仓"到当日成本，其余保留旧成本）
COST(q) = 累积分布达到 q% 的价格        WINNER(p) = 成本低于 p 的筹码比例（获利盘比例）
conc    = (COST(90)−COST(10)) / COST(50)  # 筹码集中度，越低越集中
```

- 输出：`COST(5/10/50/89/90)`、`WINNER(0.9C / 1.0C / 1.1C)`、`conc`。
- 不变式已校验：`WINNER` 单调、`COST` 单调、总和≈1（见 `chip_distribution.py` 自测）。
- **数据源铁律**：只用 TimescaleDB（QMT datadir 回填），未碰 akshare。

## 2. 指标重建（飞龙 / 抄底 / 主力 / 散户线）

按你贴的公式版本还原（常量如有出入可调）：

```
飞龙线  feilong = SQRT( EMA(C,89) × COST(89) )     # 成本中枢上沿
抄底线  chaodi  = SQRT( EMA(C,89) × COST(5)  )     # 成本中枢下沿
主力线  zl      = EMA( WINNER(1.1C) − WINNER(0.9C), 5 )   # 夹在 ±10% 的筹码厚度≈主力仓
散户线  sh      = MA( WINNER(0.9C),10 ) − MA(zl,10)        # 复刻你公式结尾
```

> 注：`zl` 用 NaN 安全 EMA 播种（前导 NaN 仍为 NaN，不从首个 NaN 污染全列——这是首版的一个坑，已修）。

## 3. 5 个买侧判据 + 两类合成买点

| 判据 | 定义（T 日，无前视） |
|---|---|
| `feilong_up` 飞龙往上 | `feilong[T] > feilong[T−5]` 且 `> feilong[T−20]` |
| `main_up` 主力增多 | `zl[T] > zl[T−5]`（夹价筹码厚度上升 = 主力在收集） |
| `conc_imp` 集中度改善 | `conc[T] < conc[T−20]`（筹码收敛 = 锁仓/收集） |
| `near_chaodi` 回踩成本下沿 | `C[T] ≤ chaodi[T] × 1.05`（价格回到成本地板附近） |
| `above_feilong` 站上成本中枢 | `C[T] > feilong[T]` |

- **抄底型买点** `buy_dip` = `feilong_up & main_up & near_chaodi`（回踩成本下沿 + 趋势向上 + 主力收集）
- **突破型买点** `buy_brk` = `feilong_up & main_up & above_feilong`（站上成本中枢 + 趋势向上 + 主力收集）

## 5. 盈亏比解读（你第 4 点）

- **结构 R:R（抄底型）≈ 1.35**：止损=抄底线（买点上方约 5% 处）、目标=飞龙线（上方），
  不对称但温和——不是首版 bug 下虚高的 7.86（那是索引错位把止损压到买价下方造成的假象）。
- **实现盈亏比 payoff ≈ 1.1~1.2**：赚时赚得略多于亏时，但**胜率仅 ~41%**，平均单笔仍亏。
- 期望 −31~−34bp：**长期持有该买点会亏钱**。它不是"低风险高赔率"的圣杯，只是"比乱买少亏"。

## 6. 诚实裁定（与项目总裁定对齐）

1. **抄底型 = 温和相对选择器，不是 alpha。** 它相对全样本等权有 +7~+68bp 的小幅正超额
   （t +2~+12，统计显著），但**绝对净收益 −58~−67bp**——即它"亏得比随机买少"，自己并不赚钱。
   正超额很大程度来自：基准是"全市场等权"（含大量弱势/下行股），挑"上行中回踩+主力收集"的票
   天然跑赢市场平均。这不构成可交易 alpha。

2. **突破型明确为负**（超额 −17~−27bp，t −13~−14），与项目"动量/突破类全证伪"旧裁定一致。

3. **推翻了首版一次"假阳性"。** 首版曾报出"抄底型超额 +61~+126bp、t=+44~+49"的惊人结果，
   经核查是 `build_signals` 里 `g.sort_values('date').reset_index(drop=True)` 把每只股票的索引重置为
   局部 0 起，导致 `chip_df.loc[g.index]` 用局部索引当全局位置、除第一只外全读成**第一只股票的筹码**，
   使 `near_chaodi` 误触发 27 万次。修复后信号降到 1.44 万次、结果回到"温和负绝对"。
   **此例再次印证项目铁律：出惊人正 IC/正超额先查对齐，不是庆祝。**

4. **与既有裁定完全一致**：战法2/低吸（dixi 终审）、飞龙/主力（COST/WINNER 族）、动量/反转族，
   全 A 真实面板上均无**正绝对 alpha**；本验证把此前"因缺筹码数据不可复现"的飞龙/主力线补上后，
   结论仍是"无正绝对 alpha"，只是多了个"温和相对选择器"的细分结论。

## 7. 这个指标能怎么用（不夸大）

- ❌ **不能当独立买入信号**（绝对收益为负，跟它买亏钱）。
- ✅ **筹码工具本身（COST/WINNER）是可复用资产**：`tools/chip_distribution.py` 已能正确还原
  获利盘比例、成本中枢、集中度，可用于后续研究（主力吸筹检测、底部筹码锁定、解套盘压力等）。
- ✅ **抄底型可作"相对强度/仓位排序"过滤器**：在已选好的股票池里，优先选"飞龙往上+主力增多+
  回踩抄底线"的票（它们相对抗跌），而非单独开仓依据。
- ⚠️ 任何基于此的新策略，须先显著跑赢**同池等权**（项目铁律），且要做 walk-forward / 留年 OOS 复核。
