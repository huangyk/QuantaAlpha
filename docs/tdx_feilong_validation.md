# TDX 飞龙 / 战法2(涨停回调) 指标验证报告

> 数据：TimescaleDB `bars_1d`（源自 QMT datadir 回填，全 A 真实日线）
> 区间：2014-01-02 ~ 2026-09-30，1084 万行 / 5355 只
> 方法：T+1 开盘买入、持有 H 日收盘退出；成本万 1 + 市值分层冲击；剔次新(<250 日)/ST/涨停买不进
> 脚本：`tools/validate_tdx_feilong.py`；产物：`tools/_tdx_feilong_out.json`
> 结论先行：**可回测的 3 类信号全部跑输"闭眼持有全样本"，无一有 alpha。**

---

## 1. 公式大白话拆解

用户给的是一套通达信复合指标，由 5 类零件拼成：

| 零件 | 公式 | 含义 |
|---|---|---|
| 涨停 ZT / A1 | `(C/REF(C,1)-1)*100>9.5`；`BARSLAST(ZT)` | 涨幅>9.5% 算涨停；A1=距上次涨停的交易日数 |
| **飞龙线** | `SQRT(EMA(C,89)*COST(89))` | EMA89 收盘 × 89% 筹码成本价的几何平均 → 慢速"成本中枢上沿"（红） |
| **抄底线** | `SQRT(EMA(C,89)*COST(5))` | × 5% 筹码成本价 → 成本中枢下沿（绿） |
| 均线族 | MA5/10/60/200 | 常规均线 |
| AA/BB 动量 | `JJ=(H+L+C)/3`；`AA=EMA(JJ,20)`；`出击=CROSS(AA,BB)` | 三价均值 20 日 EMA 上穿昨值 → 动量升温 |
| 凰线/凤线 | `凰=MA(C,5)+VOLALITY/2`，`凤=MA(C,5)-VOLALITY/2`（`VOLALITY=MA(MAX(H,昨开收均)-MIN(L,昨开收均),8)`） | 以"含跳空真实波幅"为带宽的通道，突破上轨=BU 买、跌破下轨=SEL 卖 |
| **A1–A8 涨停回调买点**（战法2 核心） | 见下 | 涨停后 2~13 日内回踩支撑、缩量、小实体、未破位、MACD>-1 → 低吸买点 |
| 主力/散户线 | `主力=WINNER(C*0.9)*100`；`套牢=100-MA(WINNER(C*1.1)*100,5)` | 筹码分布：获利盘比例 vs 套牢盘比例 |

**A1–A8 涨停回调买点的逐条含义**（这是整段公式里最有"选股逻辑"的部分）：
- `A1`：距上次涨停 2~13 日（回调窗口，太长不算"回调"）
- `A2`：支撑参考价 = 涨停日后一日的最低价若高于涨停日最高价，取涨停后一日收盘，否则取涨停日开盘
- `A4`：当日收盘 ≥ A2，且最低价落在 A2 的 ±3.5% 内（回踩到支撑区、没破）
- `A5`：成交量 < 昨量 且 < 5 日均量（缩量，抛压衰竭）
- `A6`：实体振幅 < 5%（小 K 线，企稳）
- `A7`：涨停以来最低收盘 ≥ A2（没破位）
- `A8`：MACD > -1（不是深度空头）

## 2. 数据可行性（重要缺口，如实告知）

| 零件 | 能否回测 | 原因 |
|---|---|---|
| 涨停回调 A1–A8、凰线突破、AA/BB 动量 | ✅ 可 | 只用 OHLCV，本库齐全 |
| **飞龙线 / 抄底线**（`COST(89)` 等） | ❌ 不可忠实复现 | `COST()` 是通达信**筹码分布**函数，需逐日换手加权持仓成本；本库 `bars_1d` 仅 OHLCV（来自 QMT datadir 回填），无筹码数据；QMT datadir 也只有 OHLCV。**不替代 akshare** |
| **主力 / 散户线**（`WINNER()`） | ❌ 不可忠实复现 | 同上，`WINNER()` 也是筹码分布函数 |

> 注：飞龙因子此前已在全 A 面板证伪（见 `docs/factor_scorecard.md`），所以"不可复现"部分本来也无可惜的 alpha；本报告的实证只覆盖可回测的 3 类信号。

## 4. 找到的规律（诚实裁定）

1. **三个信号都是"负向选择器"，不是 alpha 信号。**
   它们的原始收益微正（+13~+32bp / 5~20 日），但**全样本等权持有本身就涨更多**（基准约 +50bp/5 日，来自 2014–2026 含 2015/2019–2021 牛市的漂移）。信号挑出的票平均**跑输随机持有一只票** 40~167bp，t 值 −7 到 −20，显著性极强。超额净值一路复利到 −100%——也就是"跟信号做多、做空基准"这个组合归零。

2. **图表形态真实存在，但不预测超额收益。**
   涨停回调、通道突破、动量上穿都是 A 股里肉眼可见的规律，但回测证明它们触发后短中期**相对走弱**（胜率 46~50%，近似抛硬币）。本质是"选在已经强势/拉伸之后"，随后相对均值回归。

3. **8% 止损 = 活命，不是 alpha（与 dixi 终审一致）。**
   加 8% 止损把绝对均值收益抬到 +46~+78bp（把大亏截断在 −8%），但**相对超额仍然为负**（−29~−63bp）。印证了之前低吸终审的结论：止损只解决"亏多少"，不解决"能不能赚"。

4. **与既有裁定完全一致。**
   - 战法2（低吸/涨停回调）：此前 `docs/dixi_final_verdict.md` 已判"无止损即自杀、加止损仅回 0、无持续 alpha" → 本次更精细的 A1–A8 版本同样证伪。
   - 飞龙/主力线（COST/WINNER 族）：此前已在全 A 面板证伪 → 本次因数据缺口未复现，但不影响结论。
   - 动量族：AA/BB 出击显著负超额，与"短期反转/动量族全证伪"的 memory 裁定一致。

## 5. 这个指标能怎么用（不夸大）

- ❌ **不能当买入信号**：跟它买跑输闭眼持有。
- ✅ **可当"反向排除器"**：某票同时触发多个买点信号时，短中期相对偏弱的概率高，可作为**回避/减仓**参考，而非开仓依据。
- ⚠️ **飞龙线/主力线部分本库无法验证**：若要验证，必须补"每日筹码成本分布"数据——本库无、QMT datadir 也无，需另建（如用每日换手还原近似持仓成本），属新工程，不在本次范围。
